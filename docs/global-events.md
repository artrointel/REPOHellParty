# 헬파티 글로벌 이벤트 기획

몬스터별 특수 능력과 별개로 스테이지 전역에서 조건을 감지해 발생하는 이벤트를 관리한다. 호스트 전용·바닐라 참가자 호환 조건을 동일하게 적용한다. 난이도 0은 순정 그대로 진행한다.

| 해금 난이도 | 이벤트 및 핵심 동작 |
| --- | --- |
| 1(stage1) | **[몬스터 웨이브](events/monster-wave.md):** 가치품 파괴 후 음악 예고 3초가 지나도 20m 내 서 있는 플레이어가 있으면 사각지대에 초기 3종과 초당 노움 2마리를 소환하며, 예고를 포함해 20초 후 종료한다. |

난이도 2~5에서도 위 이벤트를 유지한다. 해당 단계만의 추가 이벤트나 강화 동작은 아직 정의하지 않았다. [몬스터 특수 능력 기획표](monster-abilities.md)와 구분하여 관리한다.
