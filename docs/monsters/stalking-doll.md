# Stalking Doll — 자율 Scream Doll (가칭)

순정 Scream Doll 가치품을 외형·애니메이션·공격 판정으로 사용하며, 난이도 1부터 Loom·Robe 등장 시 각 개체당 1마리 동반 등장하는 몬스터다. 호스트 전용 제어 코드를 붙인 인형에만 적용하며 일반 Scream Doll의 동작은 변경하지 않는다. Loom·Robe의 순정 AI는 유지한다.

## 일반 상태의 행동

- 매 갱신마다 살아 있고 활성 상태인 플레이어 중 직선거리가 가장 가까운 대상을 선택한다. 더 가까운 사람이 생기면 즉시 교체한다. 같은 거리에서는 플레이어 ID로 일관되게 선택한다.
- 한 명도 인형을 보지 않을 때만 대상을 향해 소리 없이 부유한다. 바닥 NavMesh 경로를 따라 장애물을 우회하며 지형을 통과하는 자유 비행은 하지 않는다. 경로가 없거나 물체에 막히면 정지하고 다시 경로를 구한다. 도달할 수 없다는 이유로 더 먼 사람을 대신 선택하지 않는다.
- 속도는 순정 Loom(`EnemyShadow`) 프리팹의 NavMeshAgent 기본 속도에서 읽는다. 이탈 상태 전용 속도나 임의의 추정값을 사용하지 않는다.
- 살아 있는 플레이어 중 누구든 인형을 보면 자발적인 이동·회전·공격을 중단하고 순정 Idle 상태로 전환한다. 현재 타깃 이외의 플레이어도 감시자가 된다. 관찰이 끝나면 최근접 대상을 다시 선정하여 행동을 재개한다.
- 관찰은 인형 중심·위·아래·좌우·앞뒤 지점의 시야 범위와 장애물 ray로 검사한다. 벽 뒤에서 인형 쪽으로 시선을 향하는 것만으로는 정지시키지 않는다. 20m 같은 별도 관찰 거리 제한은 없다.
- 초기 공격 거리는 직선거리 1.2m이며, 대상에게 ray가 도달할 때 순정 `ScreamDollValuable.States.Active`를 실행한다. 플레이어 공격 피해는 10이며, 판정 주기·공격 모션·비명은 순정 인형 설정을 사용한다. 공격 중 관찰되면 Idle로 복귀한다. 추적 중에는 Idle이라 비명을 재생하지 않는다.
- Grab 시도는 관찰 여부와 무관하게 시도한 플레이어에게 피해 10을 한 번 주고 잡기를 취소한다. 스토커의 체력·가격은 감소하지 않는다. 호스트가 잡기 등록을 차단하고, 시작 중인 Grab 설정이 끝나는 다음 프레임에 순정 강제 해제를 전달한다. 같은 플레이어의 0.5초 이내 중복 요청은 추가 피해 없이 해제하며, 서로 다른 플레이어는 개별 처리한다. 순정 해제 잠금 0.5초 뒤 다시 시도하면 다시 피해를 받는다. Grab 입력을 계속 누르면 순정 자동 재시도에 따라 반복해서 피해를 받을 수 있다.
- 유효한 대상이 없으면 대기한다. 체력·피해·추출·코어 보상은 아래 전용 규칙을 따른다.

## 기본 탑재 스킬: 분노

- 각 스토커의 Grab 시도 횟수는 플레이어 구분 없이 공유 누적한다. 기존 0.5초 중복 방지를 통과하여 피해를 적용하는 시도만 1회로 센다. 3번째 시도에서 즉시 분노한다. Grab 피해 10과 잡기 취소는 그대로 유지한다.
- 분노 중에는 이동속도가 Loom 기본 속도의 3배가 되며, 플레이어가 바라봐도 이동·회전·공격을 멈추지 않는다. 가장 가까운 살아 있는 플레이어를 계속 선택하고 기존 NavMesh 경로와 장애물 회피를 사용한다.
- 분노 추적 중에는 거리와 관계없이 순정 Active 상태를 유지한다. 이동 중에도 공격 애니메이션·비명과 HurtCollider를 유지하며, 실제 피해는 순정 충돌 범위·쿨타임·ray 검사에 따라 발생한다. 대상이 없으면 대기한다. 피격 정지·수면총 기절·스토커 사망 처리는 유지한다.
- 분노 시작 이후 플레이어 중 누구든 실제로 사망하면 해제한다. 현재 타깃이나 스토커가 죽인 플레이어로 제한하지 않으며, 다른 몬스터·환경·플레이어 등에 의한 사망도 포함한다. 이미 죽어 있던 플레이어나 단순 퇴장은 해제 조건이 아니다.
- 마지막 유효 타격 이후 게임 시간 30초 동안 유효 타격이 없으면 분노를 해제한다. 진입 후 한 번도 타격하지 못했다면 분노 진입 시점부터 센다. 스토커의 공격 또는 Grab 반격으로 플레이어 체력이 실제 감소한 경우 시간을 갱신한다. 무적·쿨타임 등으로 피해가 없는 접촉이나 단순 Grab 횟수 증가로는 갱신하지 않는다. 경로 막힘·타깃 부재·기절 중에도 시간을 검사한다.
- 사망 또는 무타격 시간 초과로 해제하면 속도·관찰 규칙을 즉시 원복하고 Grab 누적을 0으로 초기화한다. 이후 다시 3회 누적 시 분노한다. 분노 중의 추가 Grab은 다음 발동 횟수로 적립하지 않는다. 분노 전의 누적은 다른 플레이어의 사망으로 초기화하지 않는다. 여러 스토커가 분노 중이면 한 플레이어의 사망으로 모두 해제된다.
- 3번째 Grab의 피해로 플레이어가 죽는 경우에도 분노 진입 후 사망을 처리하므로 즉시 해제된다. 순정 `PlayerAvatar.PlayerDeathRPC`의 인증을 통과한 생존→사망 전환을 호스트에서 관찰하며, 중복 사망 메시지로 분노를 다시 초기화하지 않는다.

## 난이도 3(stage10): 폭주

- 분노 진입 조건을 하나 더 추가하는 패시브다. Grab 누적이 3회 미만이어도 스토커의 일반 공격이 플레이어에게 유효 타격을 주면 즉시 분노한다. 모든 플레이어가 대상이며 현재 추적 대상에 한정하지 않는다.
- 피격 위치·플레이어의 시선 방향·후방 각도를 조건으로 검사하지 않는다. 관찰되지 않을 때 공격하는 기존 행동은 유지하되, 동기화 지연 등으로 정면·측면에서 맞아도 유효 피해가 발생했다면 동일하게 폭주한다.
- 실제 체력 감소가 있어야 한다. 무적·장애물·공격 쿨타임으로 막힌 접촉과 Grab 반격은 폭주 발동 조건이 아니다. 바닐라 참가자의 일반 공격은 아래 체력 메시지 확인 경로로 확정한다.
- 분노의 속도 3배·관찰 무시·이동 중 공격 유지·플레이어 사망 해제·30초 무타격 해제를 그대로 사용한다. 폭주 전용 별도 분노 상태나 추가 강화 수치는 없다. 해제 뒤 새로운 일반 공격의 유효 타격을 주면 다시 분노할 수 있다.

## 네트워크와 검증 범위

호스트만 타깃·경로·관찰 상태를 계산한다. 이동은 순정 Rigidbody·PhysGrabObject·PhotonTransformView, 공격 표현은 순정 SetStateRPC·Animator·HurtCollider로 전달한다. 새 프리팹 ID·RPC나 참가자 모드를 요구하지 않는다.

호스트 자신의 시야는 카메라 FOV·화면 비율을 사용한다. 바닐라 참가자는 카메라 위치·방향을 전달하지만 실제 FOV·화면 비율은 전달하지 않으므로, 참가자 관찰 판정에는 수평 170도·수직 140도의 넓은 범위를 사용한다. 참가자에게 실제로 보이기 전에 멈출 수 있는 보수적인 판정이며 실제 화면의 픽셀 단위 가시성과 동일하지 않다. 카메라 보간·네트워크 지연과 순정 애니메이션 전환에 따른 정지/공격 중단 시차는 실제 멀티플레이로 확인해야 한다.

호스트에서 순정 Active의 무작위 물리 충격과 Grab 기반 상태 전환을 제어한다. 참가자는 원래 인형 스크립트와 애니메이션을 실행한다. 일반 인형은 이 변경의 대상이 아니다.

플레이어 공격 피해는 순정 인형의 2를 유지하고, 호스트가 같은 HurtCollider의 쿨타임·ray 판정을 거쳐 부족한 8을 순정 `PlayerHealth.HurtOther`로 전달해 총 10으로 만든다. 호스트 자신의 공격은 실제 순정 체력 감소가 확인될 때만 보충한다. Grab 피해도 이 순정 피해 메시지로 전달하며, 요청자의 Photon 소유권을 확인한다. 플레이어의 순정 무적·사망 상태는 우회하지 않는다. 바닐라 참가자의 기본 피해 판정과 호스트의 보충 판정은 서로 다른 피어에서 실행되므로, 네트워크 지연·경계 접촉 때의 피해 합계와 중단 시점은 실제 멀티플레이에서 검증해야 한다.

분노 타이머와 폭주의 유효 타격은 호스트 자신에게는 직접 체력 감소를 확인한다. 바닐라 참가자는 호스트가 유효 공격·Grab 반격을 전달한 뒤 2초 이내에 같은 참가자의 인증된 `UpdateHealthRPC`로 체력 감소가 확인되면 처리한다. 폭주는 일반 공격 후보만 등록하며 방향을 검사하지 않는다. 순정 메시지에는 공격자 정보가 없으므로 이 짧은 구간에 겹친 다른 피해와 완전히 구분할 수는 없다. 기한 밖의 감소·회복·무피해 접촉은 처리하지 않는다. 타이머용 확인만으로 이미 해제된 분노를 재발동하지 않으며, 폭주의 새 일반 공격 타격은 발동할 수 있다. 플레이어 사망 시 확인 대기 중인 후보를 취소한다.

## 생성과 테스트

생성 진입점은 `StalkingDoll.Spawn(ground, rotation)`이다. Debug/Release 모두 난이도 1(stage4)부터 순정 Loom(`EnemyShadow`)·Robe(`EnemyRobe`)의 실제 SpawnRPC를 확인한 뒤 인접한 유효 NavMesh에 스토커 1마리를 생성한다. 난이도 0은 순정 그대로 유지한다. 분노는 스토커의 기본 능력이며, 폭주만 난이도 3에 추가된다.

한 스테이지의 각 Loom·Robe 인스턴스당 동반 생성은 1회다. 순정 디스폰·재등장으로 반복 생성하지 않고, 동반 스토커를 처치해도 같은 본체가 새 인형을 보충하지 않는다. 생성된 스토커는 독립 AI로 행동하며 동반 본체의 사망·디스폰을 따라 제거되지 않는다. 인접 위치의 경로와 공간을 검사하며 최대 10초 재시도한다. 안전한 위치가 없으면 생성하지 않고 경고를 남기며, 본체가 이후 다시 등장하면 재시도할 수 있다.

현재 Debug는 난이도 2의 Mentalist 테스트 시나리오를 사용하며 시작 위치에 스토커를 추가 생성하지 않는다. 스토커는 Loom·Robe 동반 등장으로 확인한다. 수면총 등의 순정 기절 시간은 자율 행동 중지로 반영한다. 전용 수면 자세 애니메이션은 없다. 구체적인 확인 항목은 [자율 인형 플레이테스트](../stalking-doll-playtest.md)를 따른다.

## 체력·피격·보상

- 전용 체력은 100이며 피해와 사망은 체력을 기준으로 호스트에서 계산한다. 가격은 최초 순정 Scream Doll 가격 × 현재 체력 / 100을 표시 단위 아래로 버려 계산한다. 체력 75/50/25이면 가격도 최초의 75%/50%/25%다. 반복 피해 시 직전 가격이 아니라 최초 가격에서 계산하여 누적 반올림 오차를 방지한다. 가격 0이나 가치품의 15% 파괴 임계값으로 조기 사망하지 않는다.
- 순정 HurtCollider가 전달하는 적 대상 피해량·즉사·기절·피격 정지 시간을 사용한다. 순정 CanHit의 쿨타임·장애물 검사를 거치며 같은 공격의 가치품 경로로 중복 피해를 주지 않는다. 자기 공격은 제외한다.
- 벽·바닥 등 지형과의 물리 충돌로는 체력·가격이 줄거나 사망하지 않는다. 충돌 상대에 PhysGrabObject·Enemy·PlayerAvatar가 없고 Rigidbody가 없거나 kinematic인 지형에 적용한다. 일반 물건을 던져 맞히는 동적 충돌과 가치품 대상 물리 공격은 경미/중간/강한 수준별 5/10/20 피해로 변환한다. 무기·몬스터 공격과 낙사 구역 등의 명시적인 즉사 판정은 유지한다.
- 사망 시 Bella 프리팹의 EnemyParent.difficulty와 순정 EnemyParent의 코어 선택 규칙을 그대로 사용해 같은 종류의 코어를 1개 생성한다. 중복 피해·사망 콜백으로 보상을 반복 생성하지 않는다.
- 사망한 인형은 순정 네트워크 파괴 효과로 제거한다. 공격·추적은 중단한다. 스테이지 종료에 따른 일반 오브젝트 정리는 처치 보상을 생성하지 않는다.
- 순정 가격 초기화 뒤 원래 가격은 유지하고, 현재 가격만 순정 HealRPC의 signed delta로 모든 참가자에게 동기화한다. 체력 감소에 따른 가격 변경은 순정 가치품 파괴 로직을 실행하지 않는다. 인형의 추출 목록 등록은 계속 차단한다. 라운드 획득 가능 금액에도 더하지 않는다. 추출구에 가져가도 인형 자체를 계산하거나 추출 대상으로 소모하지 않는다. 처치 후 코어는 일반 순정 보상으로 추출할 수 있다.

## 호스트·바닐라 참가자의 공통 표현

호스트만 가격·발견 UI를 감추던 처리는 제거했다. 양쪽 모두 순정 발견·Grab 가격 UI를 사용하며, 표시 가격은 공유 체력 비율을 따른다. 가치는 체력 표시 역할만 하며, 기존 요구대로 추출 계산과 라운드 획득 가능 금액에는 포함하지 않는다.

피해는 체력에서 먼저 계산하고 가격을 갱신한 뒤 순정 인형 BreakRPC를 가치 손실 플래그 없이 실행한다. 따라서 호스트와 참가자 모두 같은 충격 소리·파티클·화면 반응을 사용한다. 금액 감소는 현재 가격에 반영하며, 별도의 가치 손실 숫자 팝업은 생성하지 않는다. 일반 몬스터의 붉은 재질 점멸은 호스트에도 적용하지 않는다. 순정 인형에 없는 EnemyHealth.HurtRPC나 새 피격 애니메이션을 추가하지 않는다.
