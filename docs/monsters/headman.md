# Headman

난이도 4(stage10)부터 **보호본능**을 보유한다. 0~3단계는 순정 동작을 유지한다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

## 보호본능

- 본체로부터 3차원 직선 거리 **20m 이내**에 있는 살아서 등장한 동료 몬스터가 유효한 플레이어 타깃을 보유하면 그 타깃을 공유받아 순정 추적을 시작한다. 정확히 20m도 포함하며 벽·시야 조건은 추가하지 않는다.
- 동료가 플레이어에게 실제 체력 피해를 받았을 때도 해당 동료와의 거리가 20m 이내이면 공격자를 추적한다. 총격·근접 무기·최근 플레이어가 조작한 물체의 순정 피해 발생 문맥을 사용한다. 환경 피해나 공격자를 확인할 수 없는 피해는 임의의 플레이어로 대체하지 않는다. 치명타도 피격 직전 위치를 사용한다.
- **Headman 자신에게 살아 있는 추적·공격 대상이 없을 때만** 발동한다. 이미 대상을 추적 중이면 다른 동료가 피격되어도 타깃을 덮어쓰지 않는다. 순정이 배회로 돌아간 뒤 남은 과거 타깃 참조는 현재 추적 대상으로 간주하지 않는다.
- 동료 타깃 검사는 0.5초 간격으로 하며, 여러 동료가 조건을 만족하면 가장 가까운 동료의 타깃을 선택한다. 피격 전달은 피해 처리 직후 수행한다. 별도 쿨타임은 없다.
- 동료의 순정 `playerTarget`·`targetPlayer` 참조와 공용 추적 상태를 읽는다. Huntsman은 플레이어를 향한 조사 Transform, Gnome·Banger는 순정 Director의 공유 타깃도 확인한다. Headman은 순정 `Enemy.TargetPlayerAvatar`·추적 상태와 기존 네트워크 직렬화를 사용한다.
- 스폰 애니메이션·기절·사망·디스폰 중에는 발동하지 않는다. 무조건적인 타깃 고정이나 이동속도 변경은 하지 않으며, 공유 후 추적 종료·공격은 순정 AI가 결정한다.

실제 확인은 [Headman 플레이테스트](../playtests/headman-playtest.md)를 따른다. 단계별 요약은 [기획표](../monster-abilities.md)에서 관리한다.

[Reaper 전력질주](reaper.md)는 Headman의 순정 모습과 추격 이동을 빌리는 별도 스킬이다. 이 형태는 원본 Reaper의 체력·대상을 공유하고 독립 Headman 코어를 드랍하지 않는다. 일반 자연 생성 Headman에 전력질주를 부여하지 않는다.
