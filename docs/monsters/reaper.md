# Reaper

난이도 **2(stage4)**부터 **전력질주**를 보유한다. 0~1단계에는 전력질주를 사용하지 않는다. 기존 블라인드는 제거했으며 Shadow Child의 블라인드는 유지한다. 0단계는 순정 기준으로 남지만 자연 진행에는 배정하지 않는다.

## 발동과 복귀

- 살아서 등장한 Reaper가 현재 공격 대상을 추적 중이고, 해당 대상과의 3차원 직선 거리가 **10m 이상**이면 전력질주를 사용한다. 정확히 10m를 포함한다.
- 순정 Headman 모습으로 교체하고 기존 공격 대상을 이어받아 추격한다. 이동 속도·가속·경로 이동은 Headman의 순정 `EnemyStateChase` 설정을 사용하며 임의 배수를 하드코딩하지 않는다.
- 대상에게 **3m 이내** 도달하면 즉시 Reaper로 돌아가 같은 대상에 대한 순정 추격·공격을 이어간다. 정확히 3m를 포함한다. 복귀는 쿨타임과 관계없이 수행한다.
- 쿨타임은 **사용 시점부터 10초**다. 최초 사용은 즉시 가능하며, Headman 상태에서는 다시 발동하지 않는다. 쿨타임이 Headman 상태에서 끝나더라도 3m 복귀 전까지 그 모습으로 유지한다. 10초는 Headman의 수명이나 강제 복귀 시간이 아니다.
- 대상이 사망·비활성화되면 Reaper로 복귀해 배회한다. Headman 상태에서 임의의 다른 플레이어로 공격 대상을 바꾸지 않는다.
- 배회·대기·단순 조사·타깃 탐색·기절·디스폰 상태에서는 새로 사용하지 않는다. 순정 추적 상태인 Sneak·Notice·AttackPlayer 계열·StuckAttack 계열·LookUnder 계열에서 현재 타깃을 확인한다.

## 체력·기절·보상

- 하나의 Reaper가 모습만 전환하는 스킬이다. Headman에 원본 Reaper의 최대·현재 체력을 적용하고, 그 모습에서 받은 피해도 원본에 반영한다. 복귀로 회복하지 않는다.
- Headman의 순정 피격·기절을 유지한다. 복귀 시 남은 기절 시간을 Reaper에도 적용해 변신으로 기절을 해제하지 않는다.
- Reaper 모습에서 죽으면 순정 Reaper의 사망·코어 처리를 따른다.
- Headman 모습에서 죽어도 같은 Reaper의 처치로 처리한다. Headman 자체의 코어는 차단하고, 저장된 원본 Reaper를 사망 위치로 옮겨 원본 `EnemyParent.Despawn`의 순정 코어 규칙을 한 번만 실행한다. 원본의 코어 종류·최대 드랍 횟수를 유지하며 새 Reaper를 생성해 추가 보상하지 않는다.
- 단순 모습 전환과 거리 복귀는 처치가 아니며 코어를 생성하지 않는다. Headman 개체는 원본당 하나를 재사용하며, 숨겨진 원본이나 Headman이 임의로 자동 재등장하지 못하도록 막는다. 원본의 정상 사망 후 순정 재등장으로 새 생명이 시작되면 스킬도 다시 사용할 수 있다.

## 호스트 전용 구현

- 순정 Reaper는 `EnemyRunner`, Headman은 `EnemyHeadController`가 있는 `Enemy - Head`다. Headgrab·Huntsman과 구분한다.
- 순정 네트워크 프리팹, 등록·초기화, SpawnRPC·DespawnRPC와 순정 타깃·상태 동기화를 사용한다. 참가자 전용 모델·애니메이션·사용자 정의 RPC는 추가하지 않는다.
- 전환 위치를 해당 형태의 NavMesh에 투영한다. Headman 최초 생성에는 순정 등록·초기화에 필요한 짧은 프레임 대기가 있으며, 준비가 끝나기 전까지 Reaper를 먼저 숨기지 않는다. 별도 변신 대기나 변신 전용 애니메이션은 추가하지 않는다.
- Headman 준비가 실패하거나 유효 NavMesh가 없으면 Reaper를 유지하고 실패를 기록한다. 준비는 최대 5초를 기다린다. 실패 시에도 해당 시도의 10초 간격을 유지해 매 프레임 재생성하지 않는다.
- 복귀 위치가 유효하지 않으면 Headman을 유지하고 1초 뒤 복귀를 재시도한다. 복귀 실패로 두 개체를 동시에 남기거나 체력을 초기화하지 않는다.
- Headman이 순정 처리로 이미 숨겨졌고 현 위치에 복귀할 수 없을 때에는 출발 당시 검증한 Reaper 바닥 위치를 비상 복귀 지점으로 사용한다. 두 모습 모두 계속 숨겨진 채 남는 것을 방지하기 위한 예외다.
- Headman 추격 속도와 상태·타깃은 순정 경로로 공유한다. 화면상 교체·피격·기절·코어·빠른 접근 후 3m 복귀는 바닐라 참가자를 포함해 실제 확인한다.
