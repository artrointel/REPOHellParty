# Bowtie

## 특수 능력: 형제(Brothers) / 복수

호스트만 설치하고 바닐라 참가자와 함께 플레이한다. Bowtie의 바람 공격과 사망에 순정 Elsa 소환·변신·추격을 추가한다.

## 난이도와 발동 조건

- 1단계(stage1~3): Bowtie는 순정 상태 그대로 진행한다. 0단계도 순정 기준으로 남지만 자연 진행에는 없다.
- 2~3단계(stage4~9): 형제를 부여한다.
- 4~5단계(stage10 이상): 형제를 유지하고 복수를 추가한다.
- 형제는 공용 [인지 상태](../metadata/recognition-state.md)를 따르며, Bowtie가 살아 있고 활성화된 플레이어 타깃을 보유해야 한다. 복수는 인지 조건의 예외로 본체 사망 시 발동한다.
- 플레이어 발견 직후가 아니라 순정 바람 공격이 실제 시작되는 `EnemyBowtieAnim.YellStart` 시점에 한 번 발동한다. 같은 바람 공격의 애니메이션 이벤트가 중복 호출돼도 추가 소환하지 않는다. 다음 바람 공격부터 다시 소환할 수 있다.

## Elsa 소환과 대상 공유

- 발동 시 공격 대상 플레이어의 현재 위치에 Elsa 1마리를 소환한다. 플레이어가 공중·가구 위에 있을 수 있으므로 해당 위치 반경 3m에서 가장 가까운 순정 NavMesh 바닥으로 투영한다. 유효한 바닥을 찾지 못하면 소환을 생략하고 오류를 기록한다.
- 스폰 초기화·등록과 위치 동기화는 순정 EnemyParent·Enemy 경로를 사용한다. 실제 활성화 직후 이동 에이전트를 NavMesh에 다시 등록한다.
- 공격 대상은 소환 시점 Bowtie의 플레이어 타깃을 이어받고 순정 `UpdatePlayerTargetRPC`로 전달한다. 소환 후 Bowtie가 다른 대상을 보더라도 기존 소환수를 새 대상에게 계속 재지정하지 않는다. 이후 피격 등에 따른 반응은 순정 Elsa AI를 따른다.
- 최초 대상이 사망하거나 비활성화되면 소환수는 디스폰을 시작한다.
- 형제·복수로 소환된 Elsa는 **자신을 소환한 Bowtie의 바람 공격을 무시**한다. 해당 바람의 밀침·기절·동결·피해 판정을 호스트에서 제외한다. Bowtie의 별도 이탈 접촉 공격, 다른 Bowtie의 바람, 다른 몬스터·무기 공격에는 이 예외를 적용하지 않는다. 일반 Elsa도 기존 규칙을 유지한다.
- Bowtie 본체가 먼저 사망·디스폰하더라도 이미 소환된 Elsa는 남은 수명을 따른다. 단, 4단계 이상의 사망 복수 소환이 발생하면 아래의 공통 1마리 제한에 따라 교체한다.

## 복수: 사망 후 소환

- 난이도 4부터 본체가 죽으면 사망한 물리 몸체 위치를 저장하고 **0.5초 후 그 위치에 Elsa를 소환**한다. 사망한 본체가 먼저 숨겨져도 저장한 위치를 사용한다. 바닥 위치 투영은 형제와 동일하게 주변 3m의 NavMesh를 사용한다.
- Bowtie를 죽인 플레이어가 살아 있고 활성화되어 있으면 그 플레이어를 우선 대상으로 지정한다. Bowtie의 기존 공격 대상이나 가장 가까운 플레이어가 따로 있어도 처치자를 우선한다.
- 처치자 식별에는 치명타를 처리하는 순정 피해 콜라이더의 플레이어 정보와 물리 충돌 당시의 유효한 마지막 조작자 정보를 사용한다. 같은 피해 호출 안에서만 전달하며, 과거에 공격한 플레이어를 이후 환경 사망의 처치자로 기억하지 않는다. 지원하지 않는 피해 경로에서 공격자를 식별할 수 없으면 처치자 없는 경우로 처리한다.
- 처치자가 없거나 사망·이탈·비활성화되어 있으면 저장한 사망 위치에 가장 가까운 살아 있고 활성화된 플레이어를 선택한다. 거리 계산은 3차원 직선 거리이며 별도 최대 탐색 반경은 두지 않는다. 소환 준비 중 대상이 사라져도 실제 활성화 시 근처 플레이어를 다시 확인한다.
- 아무 대상도 없으면 소환 개체는 변신·공격 없이 즉시 순정 디스폰 애니메이션 절차에 진입한다. 인스턴스를 순간 삭제하지 않는다.
- 유효한 대상이 있으면 실제 스폰 활성화 직후 순정 변신 애니메이션을 시작하고 완료 후 공격한다. **스폰 후 10초 수명·코어 미드랍·애니메이션 디스폰**은 형제와 동일하다. 10초에는 변신 시간이 포함된다.
- 한 생명당 사망 복수는 한 번만 예약한다. 중복 사망 알림으로 추가 생성하지 않는다. 스테이지가 종료되거나 바뀌면 이전 스테이지의 지연 소환은 실행하지 않는다. 본체 Bowtie의 순정 코어 보상은 변경하지 않는다.

## 변신과 공격

- 활성화 직후 순정 `TransformSmallToBig` 상태로 진입한다. 모델만 큰 모습으로 바꾸거나 변신 애니메이션을 생략하지 않는다.
- 순정 변신 RPC·애니메이션과 약 4.1초의 변신 대기를 그대로 사용하고, 완료 후 순정 `GoToPlayerBig` 상태에서 추격·공격을 시작한다.
- 공격력·이동·기절·피격 반응은 순정 Elsa를 따른다. 변신 직후 별도 추가 공격을 강제로 발생시키지 않는다.

## 수명과 동시 소환 제한

- 실제 순정 스폰 활성화 시점부터 10초 생존한다. 숨겨진 대기 위치에서 순정 초기화를 기다리는 시간은 제외하며, 변신 시간 약 4.1초는 수명에 포함한다.
- 본체 바람 면역을 구현할 수 있으므로 수명은 15초로 늘리지 않고 10초를 유지한다.
- 피해 성공 횟수는 집계하지 않는다. 최초 검토한 ‘직접 피해 3회 성공 시 디스폰’ 조건은 사용자 결정에 따라 제거했다.
- 각 Bowtie별로 형제·복수의 활성 소환수를 합쳐 최대 1마리다. 새 소환이 발생하면 이전 Elsa는 즉시 공격을 중단하고 디스폰 절차에 진입한다.
- 이전 개체가 사라지는 애니메이션과 신규 개체가 나타나는 과정은 잠시 겹칠 수 있다. 이전 개체가 계속 공격하거나 수명을 연장하지 않는다.
- 새 소환 전 교체된 대기 개체는 활성화하지 않는다. 여러 Bowtie의 소환수와 수명은 별도로 관리한다.

## 디스폰과 사망

- 10초 만료·교체·대상 소실은 인스턴스 즉시 제거 대신 순정 상태와 애니메이션을 사용한다.
- 큰 모습이면 순정 `TransformBigToSmall` 애니메이션을 거친 뒤 `DespawnSmall`로 전환한다. 작은 모습이면 바로 순정 디스폰 애니메이션을 시작한다. 최종 숨김은 애니메이션 이벤트의 `EnemyParent.Despawn`을 따른다.
- 디스폰 절차가 시작되면 일반 추격·기절 로직이 이를 취소하지 못하게 한다. 화면에서 완전히 사라지는 시점에는 애니메이션 시간이 추가되므로 10초에 순간 삭제되는 방식이 아니다.
- 사냥으로 죽은 경우는 순정 Elsa의 사망 효과와 제거 흐름을 사용한다. **소환 Elsa는 처치·만료·교체 모두 코어를 드랍하지 않는다.** 일반 Elsa의 보상 규칙은 변경하지 않는다.
- 이미 종료된 소환수는 순정 재등장 타이머로 부활하지 않는다. 바닐라 참가자와 적 인덱스를 유지하기 위해 숨겨진 등록 인스턴스는 장면 정리까지 유지한다.

## 순정 코드 검토와 확인 범위

- 바람 공격 시작, Elsa 대상·상태 전환과 변신은 모두 순정 메서드·RPC를 사용할 수 있다. 커스텀 프리팹·RPC를 참가자에게 요구하지 않는다.
- 바닐라 참가자의 `PlayerHealth.UpdateHealthRPC`는 공격자를 전달하지 않으므로, 호스트가 체력 감소만으로 특정 Elsa의 직접 피해 성공을 정확히 확정할 수 없다. 이를 추정 집계하지 않고 3회 조건을 제외했다.
- Debug와 Release 모두 [실제 진행도](../metadata/difficulty.md)를 따른다. 이 몬스터의 전용 임시 자동 생성은 종료했다. Bowtie는 자연 생성 개체로 검증한다. Release는 실제 진행도를 따른다.
- 자동 검증은 해금·공격별 중복 소환 방지·사망 복수 중복 방지·10초 경계·교체·재등장 방지에 쓰는 수명 규칙과 설치된 게임 호출 지점을 확인한다. 실제 처치자·변신·공격·디스폰 표현과 미설치 참가자는 [Bowtie 플레이테스트](../playtests/bowtie-playtest.md)로 검증한다.

단계별 한 줄 요약은 [난이도별 기획표](../monster-abilities.md)에서 관리한다.
