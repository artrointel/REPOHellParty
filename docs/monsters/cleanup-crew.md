# Cleanup Crew

0단계는 순정 상태 그대로 진행한다. 난이도 1(stage1)부터 **끈적이는 헤드**, 난이도 2(stage4)부터 **부화**를 부여하고, 난이도 5(stage13)부터 **부화2**로 강화한다. 런타임 구현과 자동 검사를 완료했으며 실제 게임 확인은 [플레이테스트](../playtests/cleanup-crew-playtest.md)를 따른다.

폭발헤드를 플레이어 사이에서 주고받는 폭탄으로 만들고, 폭발 뒤에는 알처럼 내부에서 몬스터가 태어나도록 한다. 가까이 모인 동료에게 위험을 넘길 수 있지만, 전달해도 폭발까지의 시간은 늘어나지 않는다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

## 1단계(stage1): 끈적이는 헤드

- 청소부가 던진 순정 폭발헤드가 자신의 현재 공격 대상과 **1.5m 이내**가 되면 해당 플레이어의 머리 위에 붙어서 따라다닌다. 정확히 1.5m를 포함하며, 거리는 헤드 위치에서 대상의 순정 시야 위치까지의 3차원 직선 거리로 측정한다. 최초 부착은 별도 대기 없이 가능하며 쿨타임을 시작하지 않는다.
- 머리에 붙은 뒤에는 헤드 기준 1.5m 안의 **다른 살아 있는 플레이어** 중 장애물 없이 도달 가능한 최근접 플레이어에게 옮겨 붙는다. **쿨타임은 기존 머리에서 떨어지는 순간부터 3초**다. 전달은 기존 주인에게서 분리됨과 동시에 새 주인에게 붙는 동작이며, 그 순간부터 다음 전달을 3초간 막는다. 최초 부착 직후라도 다른 플레이어가 조건에 들어오면 첫 전달은 즉시 가능하다. 근처에 다른 플레이어가 없으면 현재 머리에 계속 붙어 있다. 여러 헤드는 각각 독립적으로 판정한다.
- 본인이나 동료가 헤드를 **Grab하면 즉시 부착을 해제**하고 순정 잡기·던지기를 이어간다. 잡고 있는 동안에는 자동으로 붙지 않는다. Grab으로 떼어낸 순간부터 3초 대기를 적용하며, 오래 붙어 있었더라도 분리 후 3초를 전부 기다린다. 반복 Grab 확인만으로 대기를 연장하지 않는다. 놓은 뒤 쿨타임이 끝나면 순정 헤드의 현재 타깃에게 다시 접근·부착할 수 있다. 다시 붙는 것 자체로는 쿨타임을 시작하지 않는다.
- 부착·전달 시 순정 타깃 설정 경로로 머리 주인을 공격 대상으로 지정한다. Grab 중에는 순정의 Grab한 플레이어로 타깃 변경하는 동작을 유지한다. **부화·부화2는 폭발 당시의 최종 타깃**을 이어받는다.
- 순정 투척·구르기·폭발 예고·폭발과 독가스를 유지한다. 붙거나 전달하거나 떼어내도 폭발 타이머를 초기화·연장하지 않는다. 순정 폭발 예고 중에도 붙어 있거나 전달될 수 있지만 실제 폭발 후에는 추가 부착하지 않는다.
- 사망·퇴장한 플레이어에게서는 떨어지고, 헤드 비활성화·폭발·스테이지 종료 시 부착을 정리한다. 순정 헤드를 다음 공격에서 다시 던지면 기존 부착·쿨타임을 초기화한다. 벽이나 차폐 물체를 관통해서 최초 부착·전달하지 않는다.
- 헤드의 기존 콜라이더와 Grab 기능을 유지하고 호스트가 물리 위치를 갱신한다. 순정 물리 위치 동기화와 타깃 RPC를 사용하므로 바닐라 참가자는 모드 없이 동일한 헤드를 보고 잡을 수 있다. 부착 중에는 호스트의 헤드와 해당 플레이어 간 충돌만 임시 제외하고, 해제·전달 시 원래 상태를 복원한다. 네트워크 지연에 따른 원격 위치 차이는 실제 플레이에서 확인한다.

## 2단계(stage4): 부화

- Cleanup Crew가 순정 공격으로 생성한 폭발헤드가 실제로 폭발했을 때 발동한다. 헤드 생성이나 단순 디스폰 시점에는 발동하지 않는다.
- 폭발 순간의 위치와 해당 폭발헤드의 공격 대상을 저장한다.
- 폭발 당시 헤드에 공격 대상이 없다면 소환을 예약하지 않는다. 근처의 다른 플레이어로 대체하지 않는다.
- 공격 대상이 있으면 **폭발 2초 후**, 저장한 폭발 위치에 **Spewer 1마리**를 소환한다.
- 소환된 Spewer는 폭발헤드가 폭발 당시 공격 대상으로 삼았던 플레이어를 그대로 이어받는다. 대기 중 본체나 다른 헤드의 타깃이 바뀌어도 저장한 타깃을 덮어쓰지 않는다.
- 실제 스폰 시점부터 **10초 후 디스폰**한다. 폭발 후 소환을 기다리는 2초는 수명에 포함하지 않는다.
- 소환된 Spewer는 플레이어가 처치하더라도 **코어 구슬을 드랍하지 않는다.** 시간 만료 디스폰도 코어 보상을 발생시키지 않는다.

난이도 3~4에서도 이 효과를 유지한다.

## 5단계(stage13): 부화2

- 부화의 소환 몬스터를 **Spewer에서 Upscream으로 대체**한다. 두 종류를 함께 소환하지 않는다.
- 폭발 당시 타깃 필수, 폭발 위치에서 2초 후 1마리 생성, 헤드의 타깃 계승, 실제 스폰부터 10초 수명, 코어 미드랍 규칙은 동일하게 유지한다.
- **플레이어에게 순정 던지기 공격을 적용하면 10초가 남아 있어도 즉시 디스폰을 시작한다.** 유효타 기준은 `EnemyUpscreamAnim.AttackImpulse`에서 살아 있는 대상에게 넘어짐·발사 힘·회전·착지 피해 설정을 적용한 순간이다. 실제 착지나 체력 감소를 기다리지 않는다. 던지기와 이후 순정 착지 피해는 그대로 이어진다.
- 이 조기 디스폰은 부화2로 태어난 Upscream에만 적용한다. Spewer 및 일반·다른 경로로 생성된 Upscream에는 추가하지 않는다. 중복 공격 애니메이션 이벤트가 다시 던지기를 적용하지 않도록 막는다.

## 부화 공통 처리 원칙

- 발동 여부와 계승 타깃은 본체의 현재 인지 상태가 아니라 **폭발헤드 자신의 폭발 당시 공격 대상**으로 판정한다.
- 한 헤드의 한 번의 폭발은 소환을 한 번만 예약한다. 폭발 콜백·네트워크 알림 중복으로 추가 생성하지 않는다. 서로 다른 헤드의 폭발은 각각 판정한다.
- 디스폰은 인스턴스 즉시 삭제가 아닌 순정 디스폰 상태·애니메이션 흐름을 사용한다.
- 완전히 디스폰된 부화 소환수는 2초간 통신 대기 후 같은 스테이지·같은 프리팹의 다음 부화에 재사용한다. 새 부화 시 타깃·수명·공격 적용 상태를 초기화하며, 순정 스폰 연출과 10초 수명·코어 없음 규칙은 유지한다. 웨이브나 순정 개체는 재사용 대상으로 삼지 않는다. 새 인스턴스의 Photon ViewID 여유가 부족하면 해당 부화는 건너뛰고 공용 용량 경고를 남긴다.
- 스테이지 종료·전환 시 이전 스테이지의 대기 중 소환을 취소하고 소환수의 수명 관리 상태를 정리한다.
- 폭발 당시 대상이 이미 사망·비활성 상태이거나, 2초 대기 중 사망·이탈하면 소환을 취소한다. 다른 플레이어로 대체하지 않는다. 스폰 대기 중 또는 소환 이후 대상이 사라지면 소환수도 순정 디스폰으로 정리한다.
- 폭발 위치를 우선 사용하고, 해당 몬스터의 NavMesh 종류·높이·반경을 기준으로 폭발 위치에서 3m 이내의 빈 지점까지 보정한다. 벽을 가로지르는 보정과 대상까지 연결되지 않은 이동 영역은 제외한다. 유효한 위치가 없으면 해당 소환만 취소하고 원인을 경고로 남긴다.
- 부화에는 별도 쿨타임이나 동시 소환 상한이 없다. 서로 다른 폭발헤드는 각각 1마리씩 소환할 수 있다. 끈적이는 헤드의 분리 후 3초 쿨타임은 다음 부착·전달을 제한하며 부화 예약을 막지 않는다.

## 순정 구현 경로

- 끈적이는 헤드는 순정 헤드의 갱신 후 타깃·거리·차폐·Grab 상태를 검사한다. 기존 `PhysGrabObject`의 물리 위치 동기화와 `EnemyBombThrowerHead.UpdatePlayerTarget`을 사용하며 추가 네트워크 인스턴스를 생성하지 않는다. 부착 중에는 순정 상태 머신의 물리 추적만 멈추고 프레임별 폭발 타이머·예고·폭발 처리는 유지한다.
- 호스트가 인증된 `GrabPlayerAddRPC`를 받은 뒤 부착을 해제한다. 싱글플레이는 순정 `GrabStarted` 완료 후 처리한다. 실제 폭발·비활성화 후에는 부착을 차단하고, 다음 인증된 `Spawn` 전환에서 새 투척으로 초기화한다.
- Cleanup Crew는 `EnemyBombThrower`, 폭발헤드는 `EnemyBombThrowerHead`다. 실제 `ExplodeRPC`의 호스트 인증을 확인한 뒤 폭발 직전 위치와 헤드 자신의 `playerTarget`을 저장한다. 순정 폭발 처리가 완료된 경우에만 예약한다.
- 같은 헤드는 여러 공격에서 재사용된다. 한 폭발에서는 한 번만 예약하고, 다음 순정 `Spawn` 상태 전환에서 중복 방지를 초기화한다. 부모 몬스터가 죽거나 헤드가 비활성화되어도 이미 예약된 소환은 현재 스테이지에서 이어진다.
- 소환 몬스터 종류는 폭발 순간의 난이도로 결정해 저장하며, 예약 후에는 바꾸지 않는다.
- Spewer는 `EnemySlowMouth`의 순정 대상 설정과 `Notice`, Upscream은 순정 대상 인지 경로를 사용한다. 본체의 등장 연출이 끝난 뒤 저장한 대상을 초기 공격 대상으로 설정한다. 이후 대상 변경은 순정 AI를 따른다.
- 실제 `EnemyParent.SpawnRPC`에서 10초 수명을 시작한다. 예약 대기·생성 준비 시간은 제외하지만 순정 등장 애니메이션은 수명에 포함한다. 만료 후에는 `EnemyState.Despawn` 및 각 몬스터의 순정 축소·사라짐 연출로 종료한다. 기절이나 붙기 해제 콜백이 만료된 Spewer를 다시 활성화하지 못하도록 한다.
- 코어 생성은 초기화·실제 스폰·사망 처리에서 모두 차단한다. 종료된 소환수가 순정 재등장 타이머로 다시 스폰되지 않도록 한다. 별도 프리팹·사용자 정의 RPC는 추가하지 않는다.

자동 검사는 끈적이는 헤드의 해금·1.5m 경계·최초 부착 대기 없음·분리 시점부터 3초 대기·Grab 중 부착 차단·폭발 후 중단·다음 투척 초기화와 부화의 대체 단계·폭발 중복·재사용·수명·RPC 인증을 확인한다. 원격 참가자 화면의 머리 위치·자기 머리의 헤드 Grab·플레이어 간 전달·폭발 및 부화·디스폰 연출은 실제 멀티플레이에서 확인해야 한다.

단계별 신규 효과 요약은 [난이도별 기획표](../monster-abilities.md)에서 관리한다.
