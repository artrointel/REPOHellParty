# Cleanup Crew

0~1단계는 순정 상태 그대로 진행한다. 난이도 2(stage4)부터 **부화**를 부여하고, 난이도 5(stage13)부터 **부화2**로 강화한다. 런타임 구현과 자동 검사를 완료했으며 실제 게임 확인은 [플레이테스트](../playtests/cleanup-crew-playtest.md)를 따른다.

폭발헤드를 알처럼 취급하여, 헤드가 터진 자리에서 내부의 몬스터가 태어나는 컨셉이다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

## 2단계(stage4): 부화

- Cleanup Crew가 순정 공격으로 생성한 폭발헤드가 실제로 폭발했을 때 발동한다. 헤드 생성이나 단순 디스폰 시점에는 발동하지 않는다.
- 폭발 순간의 위치와 해당 폭발헤드의 공격 대상을 저장한다.
- 폭발 당시 헤드에 공격 대상이 없다면 소환을 예약하지 않는다. 근처의 다른 플레이어로 대체하지 않는다.
- 공격 대상이 있으면 **폭발 2초 후**, 저장한 폭발 위치에 **Spewer 1마리**를 소환한다.
- 소환된 Spewer는 폭발헤드가 폭발 당시 공격 대상으로 삼았던 플레이어를 그대로 이어받는다. 대기 중 본체나 다른 헤드의 타깃이 바뀌어도 저장한 타깃을 덮어쓰지 않는다.
- 실제 스폰 시점부터 **10초 후 디스폰**한다. 폭발 후 소환을 기다리는 2초는 수명에 포함하지 않는다.
- 소환된 Spewer는 플레이어가 처치하더라도 **코어 구슬을 드랍하지 않는다.** 시간 만료 디스폰도 코어 보상을 발생시키지 않는다.

난이도 3~4에서도 이 효과를 유지한다.

## 5단계(stage13): 부화2

- 부화의 소환 몬스터를 **Spewer에서 Upscream으로 대체**한다. 두 종류를 함께 소환하지 않는다.
- 폭발 당시 타깃 필수, 폭발 위치에서 2초 후 1마리 생성, 헤드의 타깃 계승, 실제 스폰부터 10초 수명, 코어 미드랍 규칙은 동일하게 유지한다.
- **플레이어에게 순정 던지기 공격을 적용하면 10초가 남아 있어도 즉시 디스폰을 시작한다.** 유효타 기준은 `EnemyUpscreamAnim.AttackImpulse`에서 살아 있는 대상에게 넘어짐·발사 힘·회전·착지 피해 설정을 적용한 순간이다. 실제 착지나 체력 감소를 기다리지 않는다. 던지기와 이후 순정 착지 피해는 그대로 이어진다.
- 이 조기 디스폰은 부화2로 태어난 Upscream에만 적용한다. Spewer 및 일반·다른 경로로 생성된 Upscream에는 추가하지 않는다. 중복 공격 애니메이션 이벤트가 다시 던지기를 적용하지 않도록 막는다.

## 공통 처리 원칙

- 발동 여부와 계승 타깃은 본체의 현재 인지 상태가 아니라 **폭발헤드 자신의 폭발 당시 공격 대상**으로 판정한다.
- 한 헤드의 한 번의 폭발은 소환을 한 번만 예약한다. 폭발 콜백·네트워크 알림 중복으로 추가 생성하지 않는다. 서로 다른 헤드의 폭발은 각각 판정한다.
- 디스폰은 인스턴스 즉시 삭제가 아닌 순정 디스폰 상태·애니메이션 흐름을 사용한다.
- 스테이지 종료·전환 시 이전 스테이지의 대기 중 소환을 취소하고 소환수의 수명 관리 상태를 정리한다.
- 폭발 당시 대상이 이미 사망·비활성 상태이거나, 2초 대기 중 사망·이탈하면 소환을 취소한다. 다른 플레이어로 대체하지 않는다. 스폰 대기 중 또는 소환 이후 대상이 사라지면 소환수도 순정 디스폰으로 정리한다.
- 폭발 위치를 우선 사용하고, 해당 몬스터의 NavMesh 종류·높이·반경을 기준으로 폭발 위치에서 3m 이내의 빈 지점까지 보정한다. 벽을 가로지르는 보정과 대상까지 연결되지 않은 이동 영역은 제외한다. 유효한 위치가 없으면 해당 소환만 취소하고 원인을 경고로 남긴다.
- 별도 쿨타임이나 동시 소환 상한은 없다. 서로 다른 폭발헤드는 각각 1마리씩 소환할 수 있다.

## 순정 구현 경로

- Cleanup Crew는 `EnemyBombThrower`, 폭발헤드는 `EnemyBombThrowerHead`다. 실제 `ExplodeRPC`의 호스트 인증을 확인한 뒤 폭발 직전 위치와 헤드 자신의 `playerTarget`을 저장한다. 순정 폭발 처리가 완료된 경우에만 예약한다.
- 같은 헤드는 여러 공격에서 재사용된다. 한 폭발에서는 한 번만 예약하고, 다음 순정 `Spawn` 상태 전환에서 중복 방지를 초기화한다. 부모 몬스터가 죽거나 헤드가 비활성화되어도 이미 예약된 소환은 현재 스테이지에서 이어진다.
- 소환 몬스터 종류는 폭발 순간의 난이도로 결정해 저장하며, 예약 후에는 바꾸지 않는다.
- Spewer는 `EnemySlowMouth`의 순정 대상 설정과 `Notice`, Upscream은 순정 대상 인지 경로를 사용한다. 본체의 등장 연출이 끝난 뒤 저장한 대상을 초기 공격 대상으로 설정한다. 이후 대상 변경은 순정 AI를 따른다.
- 실제 `EnemyParent.SpawnRPC`에서 10초 수명을 시작한다. 예약 대기·생성 준비 시간은 제외하지만 순정 등장 애니메이션은 수명에 포함한다. 만료 후에는 `EnemyState.Despawn` 및 각 몬스터의 순정 축소·사라짐 연출로 종료한다. 기절이나 붙기 해제 콜백이 만료된 Spewer를 다시 활성화하지 못하도록 한다.
- 코어 생성은 초기화·실제 스폰·사망 처리에서 모두 차단한다. 종료된 소환수가 순정 재등장 타이머로 다시 스폰되지 않도록 한다. 별도 프리팹·사용자 정의 RPC는 추가하지 않는다.

자동 검사는 해금·대체 단계, 헤드별 폭발 중복과 재사용, 수명 시작·종료 및 취소, 순정 RPC 인증·메서드를 검사한다. 원격 참가자 화면의 타깃 추적·이동·부착 해제·디스폰 연출은 실제 멀티플레이에서 확인해야 한다.

단계별 신규 효과 요약은 [난이도별 기획표](../monster-abilities.md)에서 관리한다.
