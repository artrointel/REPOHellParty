# Birthday Boy

## 특수 능력: 풍선강화1 / 풍선강화2

Birthday Boy가 생성하는 순정 풍선에 플레이어 추적과 파열 시 생성 효과를 추가한다. 호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 것을 필수 조건으로 한다.

## 난이도별 효과

- 0단계: 순정 상태 그대로 진행한다. 풍선 강화 효과를 적용하지 않는다.
- 1~3단계 — 풍선강화1: 풍선이 주변 플레이어를 감지하면 장애물을 확인한 뒤 천천히 추적한다.
- 4~5단계 — 풍선강화2: 풍선강화1을 유지하고, 플레이어가 터뜨린 풍선에서는 Gnome을 생성한다. 본체 사망으로 터지는 풍선은 아래의 Eyeball 보상 규칙으로 대체한다.

## 풍선강화1: 플레이어 추적

- [인지 상태 메타데이터](../metadata/recognition-state.md)에 따라 본체가 플레이어 타깃을 보유한 상태에서 풍선 추적 능력을 사용한다.
- 각 풍선은 자신의 위치를 기준으로 반경 3m 이내의 플레이어를 감지한다.
- 감지한 플레이어를 향해 ray를 쏘아 장애물을 확인한다. ray가 장애물에 막히지 않고 해당 플레이어에 도달할 때 추적 이동한다.
- 풍선은 플레이어를 향해 초속 0.5m의 이동 속도로 천천히 다가가는 가속 이동을 한다. 별도 가속도 수치는 지정하지 않았다.
- 주변 플레이어 감지와 ray 판정은 풍선별로 수행한다. 본체의 타깃 보유 조건과 풍선의 3m 감지 조건은 별개다.
- 순정의 풍선 접촉·파열 및 Birthday Boy의 공격 시작 동작을 유지한다. 풍선이 스스로 다가가 접촉을 유도하여 회피 부담을 높이는 것이 기획 의도다.

## 풍선강화2: 파열 원인별 생성

- 플레이어가 풍선을 터뜨리면 해당 풍선의 파열 위치에 순정 몬스터 Gnome을 생성한다. Birthday Boy의 순정 공격 시작 동작도 유지한다.
- Birthday Boy가 사망하면 생성했던 풍선들이 한꺼번에 터지는 순정 동작을 따른다. 이 사망 처리로 터지는 풍선에서는 Gnome을 생성하지 않는다.
- 본체 사망으로 터지는 풍선 중 가장 최근에 생성한 최대 3개에서만 순정 가치품 Eyeball을 각각 1개 생성한다. 해당 풍선이 3개보다 적으면 존재하는 개수만큼만 생성한다.
- 나머지 풍선은 본체 사망으로 터져도 Gnome이나 Eyeball을 생성하지 않는다.
- 풍선별 생성 순서와 소유 Birthday Boy를 구분하여 관리한다. 여러 Birthday Boy가 존재하면 각 본체의 풍선 중 최근 3개를 별도로 판정한다.
- 본체 사망에 의한 일괄 파열과 플레이어에 의한 파열을 구분하고, 동일 풍선에서 Gnome과 Eyeball을 중복 생성하지 않는다. 사망 처리로 발생한 파열에는 사망 보상 규칙을 적용한다.
- 사망 시 Eyeball 생성은 기존 풍선의 사망 후 보상 처리로, 인지 조건과 무관하게 실행한다. 본체 사망으로 모든 보상이 인지 조건에 막히지 않도록 한다.
- 플레이어 파열 이외의 원인으로 풍선이 터지는 경우에는 추가 생성 효과를 임의로 부여하지 않는다.

난이도별 요약은 [특수 능력 기획표](../monster-abilities.md)에서 관리한다.
