# Robe

0단계는 순정 상태 그대로 진행한다. 난이도 1(stage4)부터 등장 시 [스토커](stalking-doll.md)를 본체 개체당 1마리 동반 생성한다. 본체의 순정 AI는 유지하며, 순정 재등장으로 스토커를 중복 생성하지 않는다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

스토커는 분노를 기본 탑재하며 난이도 3(stage10)부터 일반 공격의 유효 타격으로도 분노하는 폭주를 보유한다. 상세 규칙은 [스토커](stalking-doll.md)와 [난이도별 기획표](../monster-abilities.md)를 따른다.
