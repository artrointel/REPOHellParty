# Bella

## 특수 능력: 자폭 / 미끼

호스트만 설치하고 바닐라 참가자와 함께 플레이한다. 순정 Clown Doll·Tiny 가치품과 순정 Bella 공격 AI를 사용한다.

## 난이도별 효과

- 0단계(stage1~3): 순정 상태 그대로 진행한다.
- 1~2단계(stage4~9): 자폭을 부여한다.
- 3~5단계(stage10 이상): 자폭과 미끼를 부여한다.

## 자폭: 인형 생성과 고정

- 능력이 부여된 Bella가 스폰되면 자전거 의자에 순정 Clown Doll 1개를 생성한다. 설치된 순정 프리팹의 `seat` 트랜스폼을 사용한다.
- 인형은 의자 위치와 방향을 따라 움직인다. 생존 중 고정된 인형은 잡아서 떼어낼 수 없다. 본체가 자연 디스폰되면 인형도 숨기고, 재등장하면 같은 인형을 다시 표시한다.
- 인형이 자폭하거나 파괴되면 해당 생존 기간에는 재생성하지 않는다. 자연 디스폰·재등장으로 복구하지 않는다.

## 자폭: 벨과 순정 인형 연동

- 순정 Bella의 경고는 `BellRing`·`BellRing2`·`BellRing3` 단계이며 각각 한 번·두 번·세 번의 짧은 벨 울림을 포함한다. 인형 진행은 실제 울림마다 누적하지 않고 각 경고 단계의 첫 울림에 한 번씩 연동한다.
- 첫 경고 단계는 첫 번째 인형 경고, 두 번째 단계는 두 번째 경고, 세 번째 단계는 순정 자폭 카운트다운을 요청한다.
- 순정 `ClownTrap.TouchNose`를 호출해 바닐라 참가자에게도 동일한 경고·애니메이션·카운트다운을 전달한다. 피해량·범위·지연과 효과는 순정 인형을 따른다. 플레이어 전용 피해로 제한하지 않는다.
- **탑재 인형의 직접 폭발 피해는 소유 Bella에게 적용하지 않는다.** 해당 인형이 생성한 폭발 콜라이더의 순정 `enemyHost`에 소유 Bella를 지정해 자신 피격을 제외한다. 플레이어·다른 Bella·다른 몬스터의 피해는 순정 규칙을 유지한다. 다른 폭발·무기·가스에 대한 Bella의 면역은 부여하지 않는다. 주변 물품이 연쇄 폭발하는 경우 그 별도 폭발에는 이 예외를 적용하지 않는다.
- 인형의 순정 애니메이션이 진행 중이면 다음 요청은 애니메이션이 끝날 때까지 대기한다. 피격 등으로 Bella가 중간 경고 단계부터 시작해도 필요한 순정 인형 경고를 차례로 처리한다. 따라서 단계 건너뛰기나 빠른 연속 경고에는 인형의 실제 경고·자폭 시작이 벨보다 늦을 수 있다.
- Bella가 경고를 중단하거나 낮은 단계에서 다시 시작해도 인형의 경고 진행은 초기화하지 않는다. 이미 처리한 단계의 추가 울림은 인형을 다시 진행시키지 않는다.
- 능력은 순정 경고 이벤트에 연동한다. 순정 Bella는 벨 경고 중 `playerTarget`이 아직 비어 있을 수 있으므로 기존 타깃 보유 여부를 별도 조건으로 추가하지 않는다. [공용 인지 조건](../metadata/recognition-state.md)의 예외다.

## 미끼: Tiny 가치품 드랍

- 난이도 3부터 순정 벨이 실제로 울릴 때마다 주변에 Tiny 가치품 1개를 드랍한다. 두 번째·세 번째 경고 단계의 짧은 개별 울림도 각각 포함한다.
- 로드된 순정 가치품 프리셋의 Tiny 목록에서 실제 `volumeType == Tiny`인 아이템을 무작위로 선택한다. 중복 프리팹 경로를 제외한 후보마다 같은 확률을 사용한다. 가치를 0으로 바꾸거나 가짜 외형으로 대체하지 않는다.
- 본체 주변의 장애물·이동 경로를 확인한 지점 약 1.2m 근처에 드랍하며, 적절한 인접 지점을 찾지 못하면 본체 위치 위에서 드랍한다. 이후에는 순정 물리·내구도·가치품 기능을 따른다.
- Bella별로 현재 미끼는 최대 1개다. 다음 울림에서는 직전 미끼의 Bella 연결을 먼저 끊고 조용히 제거한 뒤 새 아이템을 생성한다. 이전 물품을 플레이어가 잡고 있어도 같은 규칙을 적용한다. 다른 Bella가 생성한 미끼에는 영향을 주지 않는다.
- 이전 미끼 제거에는 충격 파괴·폭발·파괴음·파편 콜백을 실행하지 않는다. 멀티플레이에서는 순정 네트워크 오브젝트 제거로 모든 참가자와 생성 캐시에서 함께 제거한다.
- 미끼를 파괴·소모·추출한 경우에는 다음 실제 벨 울림 전까지 보충하지 않는다.
- 살아 있는 Bella의 실제 물리 몸체와 미끼의 현재 위치 사이 3차원 직선 거리가 **15m 이상**이면 미끼를 조용히 제거한다. 정확히 15m도 포함한다. 잡거나 카트로 옮기는 중에도 동일하게 적용하며, 거리 이탈 제거만으로 새 미끼를 보충하지 않는다.

## 미끼: 잡기와 공격 전환

- Bella가 살아 있고 스폰된 상태에서 현재 미끼를 누군가 새로 잡으면, 잡은 플레이어를 `playerTarget`으로 지정한다. 호스트에서 순정이 수락한 Grab 결과를 사용한다.
- 매번 새 Grab이 수락되면 별도 공격 예고 대기 없이 순정 `Attack` 상태에 즉시 진입한다. 공격 중이라도 잡은 플레이어를 다시 타깃으로 지정하고 공격 시간을 새로 시작한다. 동일 미끼·동일 플레이어에도 일회성 제한이나 재발동 쿨타임을 두지 않는다. 본체와 거리가 더 가까운 다른 플레이어로 대체하지 않는다.
- 미끼에 닿거나 물리 충격을 주는 것만으로 공격하지 않는다. 이미 잡고 있는 상태의 중복 알림에는 추가 반응하지 않는다. 놓았다가 다시 잡거나 다른 플레이어가 새로 잡으면 다시 해당 플레이어를 지정할 수 있다.
- 본체의 기존 타깃 유무와 무관하게 Grab으로 대상을 획득한다. 이후 기절·공격·돌진·공격 종료는 순정 AI를 따른다.

## Bella 사망 후 수집

- 사망 처리가 시작되면 인형의 고정과 추적을 해제하고, 아직 처리하지 않은 벨 연동 요청을 취소한다. 이미 시작된 순정 자폭 카운트다운은 취소하지 않는다.
- 파괴되지 않은 인형은 일반 수집품으로 남는다. 이미 소모된 인형은 복구하지 않으며, 별도 보상용 인형을 추가 생성하지 않는다.
- 사망 시 거리가 15m 미만인 미끼는 제거하지 않는다. Bella 연결·거리 제한·잡기 공격 반응을 해제하고 순정 가치품으로 남겨 추출구에서 정상 계산할 수 있게 한다. 이후 시신에서 15m 이상 멀어져도 유지된다. 사망 처리와 같은 프레임에 이미 15m 이상이 된 미끼는 제거한다. 사망 후 잡아도 Bella가 다시 공격하지 않는다.
- 본체가 나중에 새 생명으로 재스폰되더라도 이전에 해제한 보상 물품을 다시 연결하거나 교체하지 않는다.

## 구현과 검증

- 벨은 순정 `DoBellRing`, 공격은 `SetState`의 기존 RPC, 물품은 기존 순정 프리팹과 위치 동기화 경로를 사용한다. 바닐라 참가자에 커스텀 RPC나 에셋을 요구하지 않는다.
- 현재 Debug 자동 생성 대상은 [Bowtie](../bowtie-playtest.md)다. Bella의 자연 생성 개체에도 능력이 적용되며, Release는 실제 스테이지 난이도를 따른다.
- 단위 검증은 해금·15m 거리 경계·인형 경고 누적/대기/중단 및 설치된 게임의 호출 지점을 다룬다. 실제 자리 배치·폭발·잡기·교체·추출과 바닐라 참가자 동기화는 [Bella 플레이테스트](../bella-playtest.md)로 확인한다.

한 줄 요약은 [특수 능력 기획표](../monster-abilities.md)에서 관리한다.
