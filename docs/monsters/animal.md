# Animal

## 특수 능력: 독가스 / 분화

Animal은 현재 대상과 가까워지면 독가스를 방출하고, 고난도에서는 사망 시 두 개체로 분화한다. 호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 것을 필수 조건으로 한다.

## 난이도별 효과

- 0~1단계(stage1~6): 순정 상태 그대로 진행한다.
- 2단계(stage7~9) — 독가스: 현재 대상 플레이어가 3m 이내이면 쿨타임 10초로 방출한다.
- 3~5단계(stage10 이상) — 분화: 독가스를 유지하고, 사망 시 기본 체력 50%인 Animal 2마리를 생성한다. 독가스의 쿨타임 강화는 없다.

## 방출 규칙

- [인지 상태 메타데이터](../metadata/recognition-state.md)의 타깃 보유 조건에 더해, Animal과 **현재 타깃 플레이어** 사이의 3차원 직선 거리가 3m 이내여야 한다. 다른 플레이어가 가까워도 현재 타깃이 멀리 있으면 발동하지 않는다. 시야 확보·공격 상태는 별도로 요구하지 않는다.
- 거리는 양쪽 `transform.position`으로 판정하며 정확히 3m인 경우도 포함한다.
- 매 방출 위치는 발동 시점에 Animal이 타깃으로 보유한 **공격 대상 플레이어의 `transform.position`**이다. 해당 위치를 저장해 가스를 생성하며, 이후 플레이어가 이동해도 가스는 따라 움직이지 않는다.
- 최초로 타깃 보유와 3m 이내 조건을 모두 만족하면 바로 발동하고, 발동 시점부터 10초 쿨타임을 시작한다. 이후에도 매 발동에 두 조건을 모두 요구한다.
- 미인지·거리 이탈 중에도 쿨타임은 흐르지만 새로 방출하지 않는다. 조건을 다시 만족했을 때 쿨타임이 끝났다면 1회 방출하며, 타깃 변경·재획득·거리 재진입으로 초기화하거나 누락된 횟수만큼 연속 방출하지 않는다.
- 사망·디스폰 중에는 방출하지 않는다. 이미 생성한 가스는 타깃 상실·사망과 무관하게 순정 지속 시간 동안 남는다.

## 독가스 스펙과 피해 대상

- 순정 몬스터 **Cleanup Crew**가 소환한 헤드가 폭발한 뒤 남기는 독가스와 동일한 스펙을 사용한다.
- 가스의 플레이어 피해량, 피해 주기, 범위, 지속 시간과 시각·음향 효과는 해당 순정 효과를 따른다. 별도의 임의 수치를 정하지 않는다.
- 재사용하는 것은 폭발 후의 독가스 효과다. 헤드 자체나 폭발 순간의 직접 피해를 추가하는 기획은 아니다.
- 피해 대상만 플레이어로 제한한다. Animal 자신과 다른 몬스터에게는 이 가스로 인한 피해를 주지 않는다.
- 호스트만 모드를 설치한 상태에서도 바닐라 참가자에게 가스가 표시되고 순정 가스와 같은 플레이어 피해가 적용되어야 한다.
- 이 피해 대상 제한은 Animal의 독가스에만 적용하며, 순정 Cleanup Crew의 가스나 Apex Predator 분신의 사망 가스를 변경하지 않는다.

## 분화 규칙

- 3단계 이상에서 원본 Animal의 사망 시 발동한다. 인지 상태·거리·독가스 쿨타임과 무관한 예외이며, 순정 디스폰에는 발동하지 않는다.
- 원본은 코어를 드랍하지 않는다. 사망 위치를 저장하고 **게임 시간 0.5초 후** 그 주변에 순정 Animal 2마리를 생성해 순정 초기화·스폰을 완료한다. 원본을 처치한 샷건의 잔여 공격 판정에 새 개체가 동시에 죽는 것을 방지하기 위한 지연이다. 배치 중첩을 줄이기 위해 사망 위치 좌우 약 0.4m에서 인접 NavMesh 위치를 사용한다.
- 지연 생성은 사망한 원본 대신 스테이지 런타임에서 실행한다. 원본이 디스폰되어도 예약을 유지하며, 대기 중 스테이지가 종료되면 생성하지 않는다. 생성 지연은 분화 개체의 20초 수명에 포함하지 않는다.
- 각 개체의 최대·현재 체력은 순정 기본 체력의 50%다. 정수 체력은 소수점 내림, 최소 1로 처리한다.
- 분화 개체도 독가스를 보유하지만 다시 분화하지 않는다.
- 실제 순정 스폰 완료 시점부터 각각 20초의 수명을 계산한다. 20초 미만에 처치하면 각자 순정 코어 1개를 드랍한다. 한 마리만 잡으면 1개, 모두 잡으면 2개, 둘 다 놓치면 0개다.
- 20초에 도달하면 보상 자격과 스킬 사용을 중단하고 순정 사라지는 애니메이션을 거쳐 디스폰한다. 만료 후 애니메이션 중 공격해 죽여도 코어는 없다. 만료 직전 처치가 확정되면 사망 연출이 20초를 넘어도 보상은 유지한다.
- 처치·시간 만료된 분화 개체는 다시 스폰하지 않는다. 바닐라 참가자와 순정 몬스터 등록 목록·인덱스를 유지하기 위해 루트는 숨긴 상태로 남겨 스테이지 종료 시 정리하며, 플레이 공간에는 다시 나타나지 않는다.
- 새 개체는 초기화 동안 순정 물리 비활성 위치에 두고 실제 순정 스폰 시 사망 위치 주변으로 옮긴다. 스폰 대기 중이거나 기절 컴포넌트의 순정 `Start()` 초기화가 끝나지 않았으면 공격 콜라이더·직접 피해·기절 및 물리 업데이트를 받지 않는다. 원본을 죽인 공격이 초기화 전 개체에 적용되는 것을 막으며, 스폰·초기화 완료 후에는 일반 전투 처리를 사용한다.

## 현재 구현

- 인지 판정은 호스트의 `EnemyAnimal.playerTarget != null`에 연결한다. 방출 위치는 발동 순간의 `playerTarget.transform.position`이다.
- 설치된 게임의 Cleanup Crew 헤드가 참조하는 `Uranium Cloud`와 순정 `Valuable Museum Uranium Mug Deluxe`의 가스 데이터를 대조했다. 피해량 15, 피해 주기 0.75초, 피해 콜라이더 타이머 6초와 콜라이더 설정이 같으며, 입자 설정도 개별 Light 참조 외에는 동일하다. 입자 렌더러·가스 음향·Geiger 효과도 같은 순정 설정을 사용한다. 이 수치는 모드에 새로 하드코딩하지 않는다.
- 네트워크 매개체로 순정 `Valuables/04 Big/Valuable Museum Uranium Mug Deluxe`를 생성하고, 순정 파괴 이벤트의 `UraniumScript.Cloud`만 사용한다. Cleanup Crew 헤드나 헤드의 직접 폭발 피해는 생성하지 않는다. 일반 우라늄 가치품의 약한 가스로 대체하지 않는다.
- 매개체 가치는 순정 초기화 전에 0으로 설정해 보상과 최대 수집 금액에 추가하지 않는다. 초기화 중에는 플레이 영역 밖에 두고 순정 위치 RPC 후 파괴 RPC를 순서대로 전송한다. 준비에 약 0.35초와 프레임 대기가 필요하며, 쿨타임은 발동 요청 시점부터 계산한다.
- Animal 가스 인스턴스에만 호스트 측 `HurtCollider.enemyLogic` 및 `physLogic`을 끈다. 몬스터·물체 피해는 호스트 권한으로 차단하고, 각 플레이어 클라이언트는 순정 플레이어 피해 처리를 그대로 실행한다. 원본 프리팹과 다른 가스 인스턴스는 수정하지 않는다.
- Debug와 Release 모두 임시 추가 생성과 난이도 강제 없이 실제 진행도를 따른다. 실제 진행도에서의 확인 항목은 [Animal 플레이테스트](../animal-playtest.md)를 따른다.

난이도별 요약은 [특수 능력 기획표](../monster-abilities.md)에서 관리한다.
