# Mentalist

0~1단계는 순정 상태 그대로 진행한다. 난이도 2(stage7)부터 반사쉴드를 보유한다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

## 2단계(stage7): 반사쉴드

- 배회 상태를 본체 `EnemyFloater.targetPlayer == null`로 정의한다. 순정 Roam 상태 이름이나 시야에 플레이어가 있는지를 별도로 요구하지 않는다. 타깃을 보유한 상태에서는 반사쉴드가 발동하지 않는다.
- 배회 중 플레이어의 순정 원거리 총기 공격에 맞으면 원래 공격의 체력 피해·기절·피격 정지·총격에 따른 몬스터 물리 밀침을 차단하고 반격한다. 일반 근접 무기·던진 물건·몬스터·환경 피해는 변경하지 않는다.
- 공격한 무기의 종류와 관계없이 멘탈리스트 주변 공중에 순정 레이저총을 임시 생성하여 반격한다. 샷건·권총·수면총의 탄환과 레이저의 순정 총기 타격을 추적한다. 공격자를 식별하지 못하거나 순정 총기 타격 경로가 아닌 공격은 원래 처리를 유지한다.
- 생성 시점(0초)에 공격자의 당시 조준점 방향으로 총구와 총기의 월드 위치·회전을 확정한다. 이후 플레이어를 따라 조준하거나 멘탈리스트를 따라 총을 이동시키지 않는다. 약 1.4m 주변의 벽에 막히지 않은 위치를 선택한다.
- 생성 시점부터 게임 시간 2초가 지난 첫 프레임에 순정 레이저총의 Shooting 상태로 발사를 시작한다. 레이저총의 원래 shootTime 동안 고정 사선으로 연속 발사한 뒤 총을 제거한다. 공격자가 2초 동안 이동하면 기존 사선을 벗어나 피할 수 있다. 피해량·사거리·발사 지속시간·장애물 차폐는 반격용 순정 레이저총의 설정을 사용한다. 입력 무기의 산탄 퍼짐·탄 수·수면 효과는 반격에 복사하지 않는다.
- 샷건 한 발의 여러 산탄·같은 탄환의 재접촉은 반격 1회로 묶으며, 레이저도 연속 발사 한 차례를 반격 1회로 묶는다. 같은 발사에서 시작한 보호 판정은 나머지 산탄에도 유지한다. 첫 산탄 당시 이미 타깃을 보유해 보호받지 못한 총격이 뒤늦게 같은 발사 내에서 반사되지는 않는다.
- 서로 다른 발사는 각각 반격할 수 있으며 별도 쿨타임·동시 총기 수 제한은 지정하지 않는다. 발동 후 타깃이 생겨도 예약된 발사를 취소하거나 재조준하지 않는다. 본체 사망·디스폰·스테이지 종료 시에는 미발사 총을 정리한다.
- 임시 총은 수집 보상이 아니며 Grab을 차단한다. 원본 플레이어 총기의 위치·탄약을 변경하지 않는다. 반격 탄환은 본체를 직접 해치지 않으며, 또 다른 반사쉴드 반격을 연쇄 생성하지 않는다. 다른 플레이어·몬스터에 대한 효과는 순정 총격을 따른다.

## 구현과 검증

반격이 플레이어에게 주는 피해량은 순정 레이저총 설정을 사용한다. 바닐라 참가자는 자신의 순정 레이저 판정으로 피해를 계산하므로 호스트만 피해 계수를 변경하지 않는다.

호스트는 순정 ShootRPC·ShootBulletRPC의 발사 번호와 생성한 탄환을 연결하고, 레이저 입력은 연속 발사 시작 콜백으로 식별한다. 실제 몬스터 타격의 CanHit 검사 이후 EnemyHurt 진입 시 반사 여부를 결정하며, 보호한 총격은 순정 피해·기절 처리 전에 중단한다. 반격 프리팹은 원본 총 종류를 조회하지 않고 순정 아이템 목록의 ItemGunLaser로 고정한다. 새 RPC·프리팹 ID·참가자 모드를 추가하지 않는다. 반격의 표현과 발사는 순정 네트워크 오브젝트·StateSetRPC·레이저 콜백을 사용한다.

임시 총기 자리나 프리팹을 사용할 수 없어 반격 생성이 실패하면 오류를 기록한다. 이미 보호가 결정된 총격의 피해·기절 차단은 유지한다. 배회 판정은 공통 인지 메타데이터의 반대 조건이므로 타깃 보유 상태 발동 규칙의 예외다.

현재 Debug는 난이도 2·시작 위치 근처 Mentalist 1마리·샷건·권총·수면총·레이저총을 제공한다. 기본 타깃 없는 테스트 상태와 F6으로 전환하는 순정 인지·공격 상태를 비교할 수 있다. 테스트 조작은 Release에 포함되지 않는다. 실제 검증 항목은 [Mentalist 플레이테스트](../mentalist-playtest.md), 단계별 요약은 [난이도별 기획표](../monster-abilities.md)를 따른다. 자동 검사 506개와 Debug/Release 빌드는 Unity·바닐라 참가자와의 실제 위치·발사 동기화 테스트를 대체하지 않는다.
