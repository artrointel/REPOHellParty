# Elsa

특수 능력 기획은 미정이다. 0단계는 순정 상태 그대로 진행한다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

향후 구체적인 기획이 정해지면 이 문서와 [난이도별 기획표](../monster-abilities.md)에 함께 반영한다.

## Bowtie의 소환 개체

[형제(Brothers)·복수](bowtie.md)로 소환되는 Elsa는 각각 Bowtie의 타깃 또는 처치자/가장 가까운 플레이어를 대상으로 순정 변신 후 공격하고, 실제 스폰부터 10초 수명과 코어 없음·애니메이션 디스폰 규칙을 사용한다. 이는 Bowtie 소환 개체에만 적용하며 일반 Elsa의 능력·보상 규칙은 변경하지 않는다.
