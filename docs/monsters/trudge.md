# Trudge

난이도 1(stage1)부터 **소집**을 보유한다. 0단계는 순정 동작을 유지한다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

## 소집

- 철퇴로 바닥을 내려찍는 순정 첫 타격 판정이 시작될 때 발동한다. **플레이어 피격 여부와 관계없이 항상 발동한다.** 원안의 ‘아무도 피해를 받지 않은 경우’ 조건은 삭제했다.
- 내려찍은 바닥 위치를 저장하고 **3초 후**, Tick·Gnome·Banger 중 무작위 **2마리**를 생성한다. 각 슬롯을 독립적으로 추첨하므로 같은 종이 2마리 나올 수 있다. 한 번의 내려찍기는 한 쌍만 예약하며 다음 내려찍기에는 다시 발동한다.
- 철퇴 타격점 주변의 유효 NavMesh와 몸체 공간을 확인한다. 정확한 타격점에 설 수 없으면 가까운 빈 지점을 사용한다. 유효 지점을 찾지 못한 슬롯은 오류를 기록하고 잘못된 위치에 생성하지 않는다.
- 내려찍기 시점의 마지막 유효 추적 대상을 저장하여 생성 시 전달한다. 대상을 잃었더라도 마지막 대상이 아직 살아 있으면 공유한다. 생성 대기 중 사망·퇴장한 대상은 지정하지 않고 순정 AI에 맡긴다. 새로운 임의의 대상을 강제 선택하지 않는다.
- Gnome·Banger는 순정 Director의 타깃 지정과 공격 상태를 사용한다. 순정 무리 전체의 공유 타깃에도 영향을 줄 수 있다. Tick은 순정 타깃 동기화·Notice를 사용하며 Grab 빔 등에 반응하는 고유 AI는 유지한다.
- 생성된 몬스터에는 **헬파티 특수능력을 부여하지 않는다.** `VanillaAbilityExcluded` 표시를 소환 초기화 시 부착하여 공용 능력 연결을 차단한다.
- **추가 수명 제한이나 시간 만료 디스폰은 없다.** 살아 있는 동안 순정 거리 기반 등장 타이머를 갱신한다. 생존 개체의 디스폰 상태 진입은 Idle로 바꾸어 맵에 남긴다. 순정 사망·Banger 자폭 소모·스테이지 정리는 유지한다. 사망·퇴장한 소환수를 같은 인스턴스로 재등장시키지는 않는다. 코어 드랍은 순정 몬스터 규칙을 따른다.
- 내려찍기 후 본체가 죽더라도 이미 예약한 소환은 3초 뒤 완료한다. 스테이지 종료 시에는 이전 스테이지의 예약을 취소한다.

순정 `EnemySlowWalker`·`SlowWalkerAttack.ActiveHurtColliderFirstHit`에 연결한다. 새 공격 모션·RPC·프리팹은 추가하지 않는다. 단계별 요약은 [기획표](../monster-abilities.md)에서 관리한다.

## 실제 확인

난이도 1 이상에서 내려찍기에 맞은 경우와 완전히 피한 경우 모두 약 3초 뒤 2마리가 나타나는지 확인한다. 반복 내려찍기, 마지막 대상 전달, 바닐라 참가자의 이동·공격 동기화, 소환수의 특수능력 미부여, 본체 사망 직후 예약 완료와 스테이지 전환 취소를 확인한다. 전용 몬스터·무기 자동 생성은 제거했으며 실제 진행도의 자연 생성 개체로 확인한다. [Trudge 플레이테스트](../playtests/trudge-playtest.md)를 따른다.
