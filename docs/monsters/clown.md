# Clown

0~2단계는 순정이며 3단계(stage7)에 **레이저스태프소환**, 5단계(stage13)에 **레이저쉴드**를 추가한다. 호스트가 순정 `EnemyBeamer`와 `ValuableWizardStaff`를 제어하며 바닐라 참가자에게 새 RPC나 자산을 요구하지 않는다.

## 레이저스태프소환

- 순정 레이저 공격 상태 진입과 플레이어 대상 근접 공격 상태 진입마다 Dumgolf's Staff 1개를 소환한다. 같은 상태 반복 갱신에는 중복 생성하지 않는다.
- 본체 중심 주변 약 1.4m의 빈 위치를 찾고 Staff를 공중에 고정한다. 생성 당시 공격 대상의 시야 위치로 조준하며 이후 이동을 따라가지 않는다.
- 초기화 직후 순정 `StaffLaserRPC`로 발사한다. 순정과 같은 무작위 1~4초 지속·최대 15m 레이저와 장애물 판정을 사용한다. 별도 쿨타임이나 동시 Staff 수 제한은 없다.

## 레이저쉴드

- Mentalist와 같은 **공격 대상 참조가 없는 상태**를 사용한다. `EnemyBeamer.playerTarget == null`일 때 받은 원거리 총격의 피해·기절을 차단한다. 일반 근접·환경 피해에는 적용하지 않는다.
- 공격자를 향한 Staff를 즉시 소환하고 **2초 후** 발사한다. 생성 당시 공격자의 위치로 조준을 고정하므로 발사 전에 이동해 피할 수 있다. 원래 총기 종류와 무관하게 Staff 레이저를 사용한다.
- 동일 총격의 산탄·중복 충돌은 반격 1회로 묶으며 나머지 충돌도 차단한다. 서로 다른 총격은 각각 반격한다. 타깃이 이미 있는 Clown에게는 쉴드를 적용하지 않는다.
- 발사·고정·Grab 대응·사망 보상은 레이저스태프소환과 같은 구현이다. 순정 타깃 획득을 막거나 AI를 정지시키지 않는다.

## Staff 수명과 보상

- 고정 Staff는 파괴·추출을 막는다. Grab 시도는 강제로 해제하고 시도한 플레이어에게 피해 10을 준다. 같은 요청의 중복 피해는 막고 0.5초 잠금 후 새 시도는 다시 처리한다.
- 발사가 끝나면 Staff를 조용히 제거한다. 살아 있는 본체의 디스폰이나 스테이지 종료에도 정리한다.
- 제거 전에 본체가 사망하면 발사를 중단하고 고정을 해제하여 일반 수집품으로 남긴다. 이후 Grab 피해·추출 제한을 적용하지 않는다. 이미 제거된 Staff를 재생성하지 않으며 보상 Staff를 발사 종료 타이머로 삭제하지 않는다.
- 고정 중 물리 반동을 막는다. 본체 자신은 해당 Staff의 직접 타격에서 제외한다. 피해량은 순정 Staff 기준이다.
- 고정 Staff의 파괴는 몬스터 웨이브를 유발하지 않는다. 보상 전환 후에는 일반 수집품 규칙을 따른다.

단계·수명 경합·순정 메서드/RPC 계약은 자동 검사하며 실제 조준·피해·바닐라 동기화는 [Clown 플레이테스트](../playtests/clown-playtest.md)로 확인한다. 요약은 [기획표](../monster-abilities.md)를 따른다.
