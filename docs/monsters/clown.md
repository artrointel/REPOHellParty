# Clown

0~2단계는 순정 상태 그대로 진행한다. 난이도 3(stage10)부터 **보조레이저**를 부여하며, 난이도 4~5에서도 유지한다. 현재는 기획 단계다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

## 3단계(stage10): 보조레이저

- Clown이 플레이어를 대상으로 공격할 때마다 본체 주변에 순정 수집품 **Dumgolf's Staff** 1개를 추가 소환한다.
- 소환한 Staff에서 해당 공격 대상 플레이어를 향해 레이저를 발사한다.
- 조준은 **Staff 소환 당시 공격 대상 플레이어의 위치**를 기준으로 확정한다. 발사 준비 중이나 발사 중에 플레이어가 이동해도 추적·재조준하지 않고 처음 확정한 사선으로 발사한다.
- Staff가 소환된 이후 Clown의 공격 대상이 바뀌어도 해당 Staff의 조준은 변경하지 않는다.
- 한 번의 공격에서 콜백·네트워크 알림이 중복되어 Staff가 여러 개 생성되지 않도록 한다. 서로 다른 공격은 각각 소환을 판정한다.

## Grab 시도와 발사 종료

- 보조레이저용 Staff는 Clown이 살아 있는 동안 수집할 수 없다.
- 플레이어가 Grab을 시도하면 강제로 Grab을 해제하고 **시도한 플레이어에게 피해 10**을 준다.
- 같은 Grab 시도의 중복 요청으로 피해를 여러 번 주지 않는다. 해제 후 새로 Grab을 시도하면 다시 해제와 피해를 적용한다.
- 레이저 발사가 종료되면 해당 Staff를 제거한다. 정상 종료된 Staff는 보상으로 남지 않는다.

## Clown 사망 시 보상 전환

- Staff가 아직 제거되지 않은 상태에서 Clown이 사망하면, 남아 있는 Staff를 **수집 가능한 일반 가치품**으로 전환하여 남긴다.
- 이때 모드의 Grab 차단과 Grab 시도 피해를 해제한다. 플레이어가 가져가 추출구에서 정상적으로 정산할 수 있다.
- 보상 전환된 Staff는 기존의 레이저 발사 종료 정리로 제거하지 않는다. 사망과 발사 종료 처리가 겹치면 이미 보상 전환된 물품이 삭제되지 않도록 처리한다.
- Clown 사망 전에 이미 제거된 Staff를 보상으로 다시 생성하지 않는다.

## 구현 검토 시 정할 사항

- 순정 Staff의 네트워크 발사 제어 경로와 레이저의 피해·사거리·지속시간, 공격 1회의 정확한 이벤트 기준, 본체 주변 소환 위치·고정 방식은 구현 검토 시 정한다.
- 별도의 발동 쿨타임이나 동시 Staff 수 상한은 지정되지 않았다. Clown의 일반 디스폰과 사망은 구분하며, 사망 이외의 제거 상황에서 Staff를 어떻게 정리할지도 검토한다.
- 순정 프리팹과 참가자 측에 이미 존재하는 기능으로 구현해야 하며, 현재 문서만으로 기술 검증이나 실제 구현을 완료한 것으로 취급하지 않는다.

단계별 신규 효과 요약은 [난이도별 기획표](../monster-abilities.md)에서 관리한다.
