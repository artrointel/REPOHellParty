# Shadow Child

난이도 1부터 공통 스킬 **[블라인드](../metadata/blind.md)**를 보유한다. 이 문서의 Shadow Child가 기획에서 부르는 Child다. 0단계는 순정 상태 그대로 진행한다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 능력만 기획한다.

순정 `EnemyThinMan.playerTarget`이 같은 살아 있는 플레이어를 연속 3초간 가리킬 때마다 대상의 시야 높이에 독가스를 생성한다. 같은 대상이면 3초마다 반복하며, 대상 상실·교체·사망·디스폰·재스폰 시 타이머를 초기화한다. 구름은 생성 지점에 남고 플레이어를 따라가지 않는다.
