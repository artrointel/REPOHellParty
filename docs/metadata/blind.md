# 공통 스킬: 블라인드

Shadow Child에게 난이도 1부터 부여하며 이후 단계에서도 유지한다. 난이도 0에는 적용하지 않는다. 대상의 화면을 독가스로 가리고 피해를 주어 이동을 유도한다.

## 발동 규칙

- 각 몬스터가 같은 살아 있는 공격 대상 플레이어를 연속 3초간 유지하면 발동한다. 타깃을 처음 얻는 순간에는 발동하지 않는다.
- 같은 대상을 유지하면 **3초마다 반복**한다. 각 Shadow Child의 타이머는 독립적이다.
- 대상을 잃거나 교체하거나 대상이 사망·비활성화되면 타이머를 초기화한다. 다시 유효한 타깃을 얻은 시점부터 새로 3초를 센다.
- 본체 사망·디스폰 중에는 발동하지 않으며 재스폰 시 타이머를 초기화한다. 프레임 지연이 발생해도 밀린 횟수를 한꺼번에 발동하지 않는다.
- [인지 상태](recognition-state.md)의 타깃 보유 정의를 따른다. 별도 거리·시야·공격 애니메이션 조건은 추가하지 않는다. 타깃 교체 시 타이머 초기화는 이 스킬의 개별 규칙이다.

## 독가스

- 발동 시 대상의 `PlayerVisionTarget.VisionTransform.position`에 Animal의 기존 순정 독가스를 생성한다. 피해·범위·지속 시간은 [Animal 독가스](../monsters/animal.md)의 순정 효과를 그대로 사용하며 플레이어만 피해를 받는다.
- 구름은 생성 위치에 남는다. 플레이어가 이동하면 벗어날 수 있으며, 이전 구름은 순정 수명이 다하면 사라진다. 여러 구름이 동시에 남을 수 있다.
- 별도 축소나 카메라 부착을 적용하지 않는다. 순정 `UraniumScript.Cloud()`는 각 참가자에서 파티클과 피해 콜라이더를 원본 아이템으로부터 분리하며, 분리된 효과를 플레이어에 부착·이동·축소하는 순정 동기화 경로가 없다. 따라서 기획에서 허용한 Animal 독가스 대안을 사용한다.
- 순정 가스 운반체 초기화가 끝난 후 효과가 활성화되므로 생성 요청과 실제 구름 표시 사이에 짧은 초기화 지연이 있다. 위치는 발동 시점에 고정한다.
- 호스트에서만 발동을 판정하며 기존 순정 생성·파괴 경로로 바닐라 참가자에게도 동일한 효과를 전달한다. 추가 가치품이나 몬스터 웨이브 발동 원인이 되지 않는다.

## 코드 연결

- Shadow Child: `EnemyThinMan.playerTarget`.
- 공통 구현: `BlindAbility`, `BlindTargetClock`, `AnimalGas`.

## 실제 테스트 확인 사항

Shadow Child 확인은 [블라인드 플레이테스트](../playtests/blind-playtest.md)를 따른다. Reaper는 블라인드를 사용하지 않으며 [전력질주](../monsters/reaper.md)로 대체했다.

1. 난이도 0에서 추가 가스가 없는지 확인한다.
2. 난이도 1 이상에서 각 몬스터가 타깃을 얻은 뒤 3초 간격으로 대상 시야 높이에 가스가 생기고 피해를 받는지 확인한다.
3. 타깃 교체·상실 후에는 새로 3초를 기다리며, 재스폰 직후에도 바로 발동하지 않는지 확인한다.
4. 이동해서 구름을 피할 수 있고 몬스터는 가스로 피해를 받지 않는지 확인한다.
5. 바닐라 참가자 시점에서도 가스 위치·시각 효과·피해가 정상인지 확인한다.
