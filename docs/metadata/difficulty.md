# 공용 난이도 진행

몬스터 능력과 글로벌 이벤트가 함께 사용하는 헬파티 난이도다. 순정 게임의 난이도·달 주기와 별도로 계산하며, 호스트만 적용한다.

| 현재 스테이지 | 헬파티 난이도 |
| --- | --- |
| 1~3 | 1 |
| 4~6 | 2 |
| 7~9 | 3 |
| 10~12 | 4 |
| 13 이상 | 5 |

첫 스테이지부터 난이도 1이며, 완료한 스테이지 3개마다 한 단계씩 올라 최대 5를 유지한다. 0단계의 순정 동작 정의는 보존하지만 일반 진행에서는 0단계를 배정하지 않는다. 개별 스킬의 해금 단계 자체는 변경하지 않는다.

## 계산과 진행도

- 계산식: `min(5, 1 + max(0, levelsCompleted) / 3)`. 나눗셈은 정수 나눗셈이다.
- 표시 스테이지는 `levelsCompleted + 1`이다. 음수 진행도는 stage1·난이도 1로 보정하며, 최대 정수값도 오버플로 없이 처리한다.
- 런의 순정 `RunManager.levelsCompleted`를 매번 참조한다. 실패·재시도 자체로 별도 카운터를 올리지 않는다.
- 새 런·저장된 런의 기준도 순정이 복원한 완료 스테이지 수다. 모드가 이전 난이도를 따로 저장하거나 게임 진행도를 바꾸지 않는다.
- 기존 런을 이어 해도 새 계산식을 적용한다. 예를 들어 stage7은 난이도 3이 된다.

## 방장 화면 알림

- stage1에서는 **“HELLPARTY IS NOW ACTIVE”**만 표시한다. 몬스터 이름은 나열하지 않는다. stage4·7·10·13에서 난이도 2·3·4·5 상승을 알린다. 나머지 스테이지와 최고 난이도 유지 중에는 반복하지 않는다.
- 순정 큰 메시지 UI의 흔들림·확대·점멸 연출을 사용한다. 순정 시작 화면·달 연출과 다른 큰 메시지가 끝나면 표시하며, 표시 시간은 6초다. 다른 큰 메시지에 가려지면 양보하고 남은 시간을 이어 표시한다.
- 난이도 상승 알림은 제목 아래 작은 글씨로 해당 단계에서 능력이 해금되거나 강화되는 몬스터 이름을 나열하고 **“just got more dangerous.”**로 알린다. 능력의 세부 설명은 표시하지 않는다. 순정 몬스터의 실제 출현을 보장하는 안내는 아니다.

| 난이도 | 알림에 나열하는 몬스터 |
| --- | --- |
| 1 | 목록 없이 HellParty 적용 안내만 표시 |
| 2 | Reaper, Peeper, Animal, Birthday Boy, Bowtie, Cleanup Crew, Bella |
| 3 | Clown, Stalking Doll, Apex Predator, Animal, Birthday Boy, Bella, Mentalist |
| 4 | Headman, Loom, Huntsman, Bowtie |
| 5 | Clown, Cleanup Crew, Apex Predator, Elsa |

- 화면 배너는 방장 또는 싱글플레이 화면에만 표시한다. 별도 설정·저장은 없다. 해당 경계 스테이지를 다시 시작하면 다시 안내한다.
- 같은 시작·상승 스테이지에서 방장의 순정 TTS로 짧게 한 번 안내한다. stage1은 **“HellParty is now active.”**, 이후 상승은 **“The monsters have grown stronger.”**다. 몬스터 목록이나 능력 설명은 읽지 않는다.
- TTS는 플레이 중 상태·방장 음성 초기화·살아 있는 접속자의 로딩 완료를 확인한 후 2초 기다려 재생한다. 방장이 다른 TTS를 말하고 있으면 기다린다. 화면 배너·달 연출 대기와는 독립적으로 시작하고, 45초 이내 준비되지 않으면 생략한다.
- 멀티플레이에서는 방장 아바타의 순정 `ChatMessageSendRPC`를 전체에 보내 일반 발성으로 재생한다. 0.5.0의 추가 인자인 언어 코드는 영문 문장에 맞춰 `en-US`로 명시한다. 새 RPC는 추가하지 않는다. 방장 위치에서 나는 근접 음성이므로 거리·음성 설정에 따라 들리지 않을 수 있고, 몬스터의 소리 감지에도 영향을 줄 수 있다.
- 순정 TTS 호출에는 속도 인자가 없고 원격 재생 속도를 바꾸는 경로도 확인되지 않아 일반 속도를 사용한다. 호스트에만 속도 변경을 적용하지 않는다.
- 테스트에서 강제한 난이도가 자연 진행 난이도와 다르면 알림을 생략한다. 씬이 바뀌면 중단하고, 시작 후 90초 동안 표시 기회를 얻지 못한 안내는 폐기한다.

## 빌드 구성

기본 Debug와 Release는 위 계산을 그대로 사용한다. `-TestScenario CleanupCrew`를 명시한 별도 Debug만 테스트 난이도 5를 사용하고, 과거 프로필의 Debug 설정값은 읽지 않는다. 일반 진행의 stage1은 항상 난이도 1이다. 빌드·실행은 [개발 환경](../development.md#debug와-release)을 따른다.

## 몬스터 수량

능력 난이도와 별개로 **1~4라운드는 중형 +1, 5~9라운드는 대형 +1, 10라운드부터는 중형·대형 각각 +1**을 순정 수량에 더한다. 참여 인원이 7명 이상이면 표의 각 +1을 +2로 적용한다. 소형 수량과 순정 선정·스폰 흐름은 유지한다. 인원·라운드 기준·순정 해금 조건과 실제 확인은 [몬스터 수량 보정](monster-spawn-balance.md)을 따른다.
