# 공용 난이도 진행

몬스터 능력과 글로벌 이벤트가 함께 사용하는 헬파티 난이도다. 순정 게임의 난이도·달 주기와 별도로 계산하며, 호스트만 적용한다.

| 현재 스테이지 | 헬파티 난이도 |
| --- | --- |
| 1~3 | 1 |
| 4~6 | 2 |
| 7~9 | 3 |
| 10~12 | 4 |
| 13 이상 | 5 |

첫 스테이지부터 난이도 1이며, 완료한 스테이지 3개마다 한 단계씩 올라 최대 5를 유지한다. 0단계의 순정 동작 정의는 보존하지만 일반 진행에서는 0단계를 배정하지 않는다. 개별 스킬의 해금 단계 자체는 변경하지 않는다.

## 계산과 진행도

- 계산식: `min(5, 1 + max(0, levelsCompleted) / 3)`. 나눗셈은 정수 나눗셈이다.
- 표시 스테이지는 `levelsCompleted + 1`이다. 음수 진행도는 stage1·난이도 1로 보정하며, 최대 정수값도 오버플로 없이 처리한다.
- 런의 순정 `RunManager.levelsCompleted`를 매번 참조한다. 실패·재시도 자체로 별도 카운터를 올리지 않는다.
- 새 런·저장된 런의 기준도 순정이 복원한 완료 스테이지 수다. 모드가 이전 난이도를 따로 저장하거나 게임 진행도를 바꾸지 않는다.
- 기존 런을 이어 해도 새 계산식을 적용한다. 예를 들어 stage7은 난이도 3이 된다.

## Debug 예외

Release와 모든 전용 시나리오를 끈 Debug는 위 계산을 사용한다. Debug 테스트가 켜져 있으면 기존처럼 해당 시나리오의 강제 난이도가 우선한다. Clown 테스트가 최우선이며 난이도 5를 강제한다. 그다음 Reaper 전력질주의 2, Upscream의 5, Cleanup Crew의 선택 난이도(1/5), 그다음 Huntsman의 5를 사용한다. F9는 Cleanup Crew 테스트가 켜져 있을 때 공용 강제 난이도를 바꾼다.

실제 stage1 난이도 1을 확인하려면 [개발 환경](../development.md#debug와-release)에서 다섯 시나리오를 모두 끄거나 Release로 실행한다.
