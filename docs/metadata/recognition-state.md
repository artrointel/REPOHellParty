# 인지 상태

몬스터 특수 스킬에서 공통으로 참조하는 기획 메타데이터다. **인지 상태는 해당 몬스터가 플레이어 타깃 자체를 보유한 상태**로 정의한다.

## 판정 기준

- `chaseTarget != null`이면 인지 상태다.
- `chaseTarget == null`이면 미인지 상태다.
- 시야 안에 있는지, 직접 발견했는지, 추격·공격 중인지는 추가 조건으로 요구하지 않는다. 미리 선택한 타깃이나 시야에서 놓친 타깃도 참조가 남아 있으면 인지 상태로 본다.
- `chaseTarget`은 모드의 공통 타깃 별칭이다. 모든 순정 몬스터에 같은 이름의 필드가 존재한다는 의미가 아니다. 몬스터별 순정 타깃 필드를 이 값에 연결한다.
- 판정은 호스트에서 수행하며 바닐라 참가자에게 별도 판정 코드를 요구하지 않는다.

## 상태 전환

- `null → non-null`: 인지 시작.
- `non-null → null`: 인지 해제.
- 플레이어 A의 타깃 참조에서 플레이어 B의 참조로 변경: 인지 상태 유지. 타깃 교체만으로 스킬이나 쿨타임을 다시 시작하지 않는다.

## 스킬에서의 사용

- 별도 예외가 없는 추가 특수 스킬은 인지 상태를 발동 조건으로 사용한다. 미인지 상태에서는 새로 발동하지 않는다.
- 인지 조건 충족과 최초 즉시 발동은 별개다. 최초 발동 시점과 쿨타임의 시작·정지·유지·초기화 방식은 개별 스킬 명세에서 정한다.
- 이미 생성된 효과의 종료 여부는 개별 스킬 명세를 따른다. 인지 해제만으로 기존 효과를 일괄 제거하지 않는다.
- 몬스터의 사망·디스폰 시 스킬 사용을 중단한다. 기존 소환물·보상·효과의 처리는 개별 명세를 따른다.
- **Apex Predator의 분신1·분신2·분신3은 예외다.** 인지 여부와 무관하게 특수 능력이 적용되는 본체의 스폰 시점부터 즉시 사용을 시작한다.
