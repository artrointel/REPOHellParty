# 헬파티 난이도별 몬스터 특수 능력 기획표

스테이지 전역의 [글로벌 이벤트](global-events.md)는 이 표와 별도 관리한다. 난이도 1의 [몬스터 웨이브](events/monster-wave.md)는 개별 몬스터 능력이 아니다.

호스트만 모드를 설치하고 바닐라 참가자와 완벽하게 호환되는 특수 능력을 기획한다. 호환성은 모든 기획에 항상 적용되는 필수 조건이며, 호환되지 않는 능력은 기획에 포함하지 않는다.

## 작성 규칙

- 헬파티 난이도는 게임의 기존 난이도와 별도로 정의한다. 자연 진행은 1~5단계를 사용하며 0은 순정 동작 기준으로 남긴다.
- 표의 난이도에는 해당 단계의 시작 스테이지를 괄호로 붙인다. 예: `2(stage4)`.
- 0단계는 모든 몬스터가 순정 상태 그대로인 기준이며 자연 진행에는 배정하지 않는다.
- 첫 스테이지부터 1단계이며, 3스테이지를 완료할 때마다 다음 단계로 상승한다. 1~3스테이지는 1단계, 4~6은 2단계, 7~9는 3단계, 10~12는 4단계, 13 이상은 5단계다. 계산·재시도·이어하기·Debug 예외는 [공용 난이도](metadata/difficulty.md)를 따른다.
- 대상 몬스터와 특수 능력은 하나의 칸에 자연어로 작성하며, 각 능력 설명은 핵심 효과를 담은 한 줄로 축약하고 상세 문서 링크를 붙인다. 발동 조건, 세부 수치, 예외 규칙은 몬스터별 문서에 기록한다.
- 같은 단계의 기획이 여러 개라면 같은 칸에서 줄바꿈(`<br>`)으로 구분한다.
- 각 단계에서 새로 추가하거나 변경하는 핵심 효과를 요약한다. 이전 단계 능력의 유지·강화·대체·해제에 관한 상세 규칙은 몬스터별 문서에 기록한다.
- 능력은 새로 부여되거나 강화되는 단계에만 작성하며, 이전 단계의 효과를 유지하는 경우 반복 작성하지 않는다. 단계별 실제 적용 효과는 몬스터별 문서를 따른다.
- 앞으로 사용자가 전달하는 특수 능력 기획사항을 해당 난이도 행에 반영하고, 변경사항이 있으면 기존 설명을 수정한다.
- 몬스터별 구체적인 규칙은 [몬스터 기획 폴더](monsters/README.md)의 개별 문서에 기록하고, 이 표에는 자연어 요약과 링크를 남긴다.

## 공통 스킬 사용 조건

- 공통 조건은 [인지 상태 메타데이터](metadata/recognition-state.md)에서 관리한다. 인지는 타깃 자체를 보유한 상태(`chaseTarget != null`)를 뜻한다.
- 별도 예외가 없는 추가 특수 스킬은 인지 상태에서 사용할 수 있다. 최초 발동 시점과 쿨타임 처리는 개별 스킬 명세를 따른다.
- **Apex Predator의 분신은 예외로, 인지 여부와 무관하게 본체 스폰 시점부터 즉시 시작한다.** Crown은 기존대로 능력 부여 시 생성한다.

**Chef의 변장도 인지 조건의 예외로, 배회 중 플레이어 탐색과 Frog Grab으로 발동한다.** 상세 조건은 [Chef](monsters/chef.md)를 따른다.

코드 구조와 구현 후보는 [몬스터 인지 상태 구현 검토](monsters/recognition-review.md)에 기록한다.

Mentalist의 반사쉴드는 미인지 상태인 `targetPlayer == null`에서만 발동하는 예외다. 스토커 동반 생성은 본체의 실제 등장 시점에 수행한다. 스토커의 기본 분노와 폭주는 인지 메타데이터 대신 Grab·유효 타격을 발동 조건으로 사용한다.

## 특수 능력 기획표

| 헬파티 난이도 | 대상 몬스터 및 특수 능력 |
| --- | --- |
| 0(순정 기준) | 모든 몬스터가 순정 상태 그대로 진행한다. 추가 특수 능력과 수치 변경이 없다. |
| 1(stage1) | **[Shadow Child — 블라인드](monsters/shadow-child.md):** 같은 공격 대상을 유지하면 3초마다 해당 플레이어의 시야 높이에 순정 독가스를 생성한다.<br>**[Upscream — 변장(미믹)](monsters/upscream.md):** 자연 생성 개체가 지정된 Big 수집품 중 하나로 무작위 변장하며, Chef와 같은 내구도·해제 규칙과 순정 공격을 사용한다.<br>**[Cleanup Crew — 부화](monsters/cleanup-crew.md):** 타깃이 있는 폭발헤드가 터지면 2초 뒤 내부에서 타깃을 계승하는 무코어 Spewer 1마리가 태어나며, 스폰 10초 후 디스폰한다.<br>**[Peeper — 노움소환](monsters/peeper.md):** 유효 타격마다 본체 아래에 타깃을 공유하는 Gnome을 소환하며 Banger와 합산해 개체당 누적 10마리로 제한한다.<br>**[Loom·Robe — 스토커 동반](monsters/stalking-doll.md):** 각 본체 등장 시 기본 분노 스킬을 보유한 스토커를 개체당 1마리 동반 생성한다.<br>**[Apex Predator — 분신1](monsters/apex-predator.md):** 본체 스폰 즉시 분신 최대 1마리의 소환을 시작하며 Crown은 본체 식별 표시와 처치 보상으로 사용된다.<br>**[Bella — 자폭](monsters/bella.md):** 의자에 고정한 Clown Doll이 벨 1·2회에 경고하고 3회에 순정 자폭을 시작하며, Bella 사망 시 남은 인형을 수집할 수 있다.<br>**[Birthday Boy — 풍선강화1](monsters/birthday-boy.md):** 풍선은 3m·3초 체류 시 자동 파열하며, 일반·자동 파열 시 주변 10m 내 플레이어가 있으면 Gnome을 생성한다.<br>**[Chef — 변장(미믹)](monsters/chef.md):** 배회 중 20m 내 플레이어를 발견하면 드론 부착 불가 Frog로 변장하며, Grab 시 해제 후 순정 공격을 진행하고 파괴 시 코어를 드랍한다. |
| 2(stage4) | **[Trudge — 소집](monsters/trudge.md):** 내려찍기마다 피격 여부와 무관하게 1초 후 특수능력이 없는 Tick·Gnome·Banger 중 무작위 2마리를 소환하여 마지막 추적 대상을 공유한다.<br>**[Reaper — 전력질주](monsters/reaper.md):** 추적 대상이 10m 이상 멀어지면 Headman으로 빠르게 접근하고 3m 이내에 Reaper로 복귀하며, 사용부터 10초 쿨타임을 적용한다.<br>**[Huntsman — 납치](monsters/huntsman.md):** 공격·추적 중 7m 내 최근접 플레이어를 납치해 3초 후부터 매초 피해 2를 주고 사격·피해자 소음 반응·피해자의 본체 Grab을 차단하며, 피격·넘어짐 등에 해제 후 5초 쿨타임을 적용한다.<br>**[Mentalist — 반사쉴드](monsters/mentalist.md):** 타깃이 없을 때 총격 피해·기절을 막고 레이저총을 소환해 공격자의 당시 위치를 향해 2초 뒤 반격한다.<br>**[Peeper — 뱅거소환](monsters/peeper.md):** 유효 타격마다 공용 누적 10마리 한도 안에서 30% 확률로 타깃을 공유하는 Banger를 추가 소환한다.<br>**[Animal — 독가스](monsters/animal.md):** 현재 타깃이 3m 이내이면 10초 쿨타임으로 해당 플레이어 위치에 플레이어만 피해를 받는 순정 독가스를 생성한다.<br>**[Birthday Boy — 풍선강화2](monsters/birthday-boy.md):** 자동 파열 시 본체가 감지 플레이어를 공격 대상으로 지정한다.<br>**[Bowtie — 형제(Brothers)](monsters/bowtie.md):** 바람 공격 시작 시 대상 위치에 코어를 드랍하지 않는 Elsa를 최대 1마리 소환하며, 순정 변신 후 공격하고 스폰 10초 뒤 애니메이션으로 디스폰한다. |
| 3(stage7) | **[Clown — 레이저스태프소환](monsters/clown.md):** 공격마다 주변에 Staff를 소환해 대상의 당시 위치로 고정 사격하고 Grab 시 피해 10을 주며, 발사 종료 시 제거하되 본체 사망 시 남은 Staff를 보상으로 전환한다.<br>**[스토커 — 폭주](monsters/stalking-doll.md):** 플레이어 일반 공격의 유효 타격도 기본 분노의 추가 발동 조건이 된다.<br>**[Apex Predator — 분신2](monsters/apex-predator.md):** 분신 최대 수가 2마리로 증가한다.<br>**[Animal — 분화](monsters/animal.md):** 사망 0.5초 후 코어 대신 체력 50%인 Animal 2마리를 생성하며, 각 개체는 20초 내 처치 시 코어를 드랍하고 시간 만료 시 사라진다.<br>**[Birthday Boy — 풍선강화3](monsters/birthday-boy.md):** 본체가 피해를 받고 생존하면 주변 10m의 모든 풍선을 터뜨려 본체의 공격 대상을 우선 공유하는 Gnome을 생성한다.<br>**[Bella — 미끼](monsters/bella.md):** 벨마다 15m 거리 제한의 Tiny 미끼 1개를 교체하며, 잡을 때마다 즉시 공격하고 근처에서 본체 처치 시 미끼를 보상으로 남긴다. |
| 4(stage10) | **[Headman — 보호본능](monsters/headman.md):** 자신의 추적 대상이 없을 때 20m 내 동료의 타깃이나 동료를 공격한 플레이어를 공유받아 추적한다.<br>**[Loom — 납치](monsters/loom.md):** 추적·공격 중 장애물 없이 보이는 7m 내 플레이어를 등에 고정하며, 헌트맨과 전역 납치 슬롯·피해·해제 규칙을 공유한다.<br>**[Huntsman — 죽음의전술](monsters/huntsman.md):** 사망 위치에서 핀을 뽑은 Human Grenade 1개를 던지며, 플레이어가 폭발 전에 잡아 수납할 수 있다.<br>**[Bowtie — 복수](monsters/bowtie.md):** 본체 사망 0.5초 후 사망 위치에 Elsa를 소환해 처치자 또는 가장 가까운 플레이어를 공격하며, 코어 없이 스폰 10초 뒤 디스폰하고 대상이 없으면 즉시 디스폰한다. |
| 5(stage13) | **[Clown — 레이저쉴드](monsters/clown.md):** 타깃이 없을 때 총격 피해·기절을 막고 공격자의 당시 위치로 고정 조준한 Staff를 소환해 2초 후 반격한다.<br>**[Cleanup Crew — 부화2](monsters/cleanup-crew.md):** 부화로 태어나는 몬스터가 Upscream으로 대체되며, 플레이어에게 던지기 공격을 적용하면 즉시 디스폰을 시작한다.<br>**[Apex Predator — 분신3](monsters/apex-predator.md):** 분신 최대 수가 3마리로 증가한다. |

[스토커](monsters/stalking-doll.md)는 난이도 1부터 Loom·Robe 개체당 1마리 동반 등장하며 분노를 기본 탑재한다. 난이도 3의 폭주는 분노 진입 조건을 추가한다.
