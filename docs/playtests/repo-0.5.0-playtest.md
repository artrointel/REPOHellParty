# R.E.P.O. 0.5.0 호환성 플레이테스트

상태: 미실행. 자동 검증 결과와 빌드 방식은 [업데이트 결과](../compatibility/repo-0.5.0-upgrade.md)를 따른다.

## 준비

- 별도 테스트 프로필에 BepInExPack과 새 HellParty DLL 한 개만 설치한다. REPOLib·MenuLib과 다른 모드들은 우선 제외한다.
- 기본 Debug 또는 Release를 사용한다. 일반 빌드는 난이도·몬스터·장비를 테스트용으로 강제하지 않는다.
- 납치와 원격 피해 검증에는 살아 있는 플레이어 2명 이상이 필요하며, 참가자 한 명 이상은 모드 없이 참여한다.
- 빌드만 하려면 `scripts/Build-Dev.ps1 -Configuration Release -Offline`. 게임 종료 후 `scripts/Start-RepoDev.ps1`로 일반 Debug를 빌드·배포·실행할 수 있다. 이 실행 스크립트는 설정된 기존 개발 프로필에 배포하므로 별도 프로필을 쓴다면 [개발 환경](../development.md)의 경로 설정부터 변경한다.

## 우선 확인

| 영역 | 확인할 동작 |
| --- | --- |
| 시작 | 초기화 실패·MissingMethod·AmbiguousMatch·RPC method not found가 없고 일반 스테이지 난이도가 맞는다. |
| 알림 | stage1 활성화, stage4·7·10·13 상승 배너가 방장에게 보인다. 같은 시점 짧은 영문 TTS가 근처 순정 참가자에게 들리고 한국어 등 다른 게임 언어에서도 발음이 맞는다. |
| 오리 | 분신 상한·15m 복귀·30초 보충, 가스 사망, 분신2부터 왕관 주기, 숨김 중 처치 시 왕관 보상을 확인한다. |
| Animal·블라인드 | 가스가 타깃 위치에 생기고 플레이어만 피해를 받는다. 방장과 순정 참가자에게 가스 위치가 같고 멀리 떨어진 비활성 위치에서 터지지 않는다. 분화 지연·자식 수명·코어도 확인한다. |
| 헌트맨·룸 | 5m·시야·전역 납치 슬롯, 피해자 Grab 차단·소리 무시, 피격/넘어짐/사망 해제, 반복 납치 후 래그돌 복구를 확인한다. |
| 헌트맨 수류탄 | 사망 후 핀 뽑힌 수류탄이 생성되어 폭발하며, 폭발 전 Grab·수납이 가능하다. |
| Chef·Upscream | 변장 내구도·간접 파괴·Grab 해제·순정 공격 준비·시야 상실 해제, 드론·노움 제외를 확인한다. |
| 스토커 | 가격/체력, 피격·사망·코어, 계단/문턱/벽/다른 스토커 근접에서 이동, 분노·해제가 유지된다. |
| 클라운·멘탈리스트 | 참가자에게도 스태프/반격총 위치·조준이 맞고 사격이 정상이다. 조준 후 회피, 반격 피해 차단, 스태프 보상도 확인한다. |
| 웨이브 | 자세에 따른 3초 회피, 스폰 수·20초 종료, 음악 오브젝트 파괴, 원격 Grab 직후 종료, 연속 이벤트와 새 맵의 NavMesh를 확인한다. |
| 소환수 | Birthday Boy·Peeper·Trudge·Bowtie·Cleanup Crew 소환수의 타깃 공유·이동·공격·수명·코어 규칙을 확인한다. |
| 정리 | 상점/다음 스테이지/메뉴 전환과 재시작 시 가짜 가치품·왕관·스태프·소환수의 잔류나 지연 RPC 오류가 없어야 한다. |

각 능력의 자세한 수치와 절차는 기존 몬스터별 플레이테스트 문서를 따른다. 신규 맵 Sunstone Valley Resort와 기존 맵을 모두 확인한다. 로그와 함께 호스트/순정 참가자의 화면 차이를 기록한다.
