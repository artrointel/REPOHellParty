# 방장 난이도 알림 플레이테스트

자동 검사는 알림 발생 경계와 빌드·순정 UI 호출 계약을 검증한다. 아래 화면 확인은 별도로 필요하다. 테스트용 강제 난이도나 몬스터 생성 코드는 추가하지 않는다.

1. 기본 Debug 또는 Release에서 stage1을 시작한다. 순정 시작 화면 이후 방장에게만 “HELLPARTY IS NOW ACTIVE”가 약 6초 표시되는지 확인한다. 몬스터 목록은 없어야 한다.
2. stage4·7·10·13에서 각각 난이도 2·3·4·5 상승 제목과 해당 단계의 몬스터 목록을 확인한다. stage2·3·5·6·8·9·11·12·14 이상에서는 알림이 없어야 한다.
3. 순정 달 소개와 같은 스테이지에서는 그 연출이 끝난 뒤 알림이 나타나는지 확인한다. 다른 큰 메시지가 나타나면 내용을 덮어쓰지 않고 기다리는지 확인한다.
4. 16:9와 울트라와이드 화면에서 제목과 작은 몬스터 목록이 잘리거나 겹치지 않는지 확인한다. 메시지는 영문이다.
5. 모드 없는 참가자 화면에는 헬파티 알림이 없어야 한다. 방장과 싱글플레이어에게만 보인다.
6. 알림 전후 사망·씬 전환·메뉴 복귀 시 오류나 다음 씬에 남은 알림이 없어야 한다. 경계 스테이지를 재시작하면 안내도 다시 표시된다.
7. stage1은 방장 위치에서 “HellParty is now active.”, stage4·7·10·13은 “The monsters have grown stronger.”가 한 번만 재생되는지 순정 참가자와 확인한다. 상세 능력이나 몬스터 목록은 읽지 않아야 한다. 일반 발성·기본 속도를 사용한다.
8. 방장이 웅크린 상태에서도 일반 발성으로 안내하는지, 방장의 기존 TTS를 끊지 않고 대기하는지 확인한다. 실제 음성채팅·무음 설정·거리 감쇠와의 상호작용을 확인한다.

실제 게임 화면 검증: 미실행.
