# Loom·Robe와 스토커 플레이테스트

난이도 1부터 자연 생성 Loom·Robe의 개체별 스토커 1마리 동반을 확인한다. Loom 납치는 난이도 4(stage10) 이상, 생존자 2명 이상에서 확인한다.

호스트만 HellParty를 설치하고 바닐라 참가자와 함께 확인한다. Debug와 Release 모두 실제 진행도를 사용하며 자동 테스트 스폰·강제 난이도·전용 단축키·솔로 납치 우회는 없다. 실행·배포는 [개발 환경](../development.md#debug와-release)을 따른다. 아래 항목은 실제 게임의 회귀 확인 목록이며 자동 검사가 원격 동기화·연출 확인을 대신하지 않는다.

## 확인 항목

1. Loom·Robe가 실제 등장할 때 각 개체 옆에 스토커가 1마리씩 나타나는지 확인한다. 본체의 재등장으로 동반 생성이 중복되면 안 된다.
2. Loom에게 발견된 뒤 장애물이 없는 5m 안으로 접근한다. 생존자가 2명 이상일 때 납치되어야 하며 혼자일 때는 납치되면 안 된다. 몸체는 등에 고정되고 카메라는 자유롭게 움직여야 한다.
3. 벽 뒤에서는 납치되지 않아야 한다. 납치 중 Loom Grab 차단, 주기 피해, 피격·넘어짐에 의한 해제와 5초 재납치 쿨타임을 확인한다.
   손뼉 공격에 들어갈 거리까지 접근했을 때도 납치 조건을 만족하면 손뼉 공격보다 납치가 우선해야 한다. Loom의 공용 EnemyVision 유무와 무관하게 전용 시야 원점으로 벽 검사를 수행한다.
4. 스토커의 관찰 시 정지·미관찰 추적·기본 분노·난이도 3 이상 폭주도 확인한다. Robe 자체에는 납치를 부여하지 않는다.
5. 바닐라 참가자가 있을 때도 동반 생성·납치·해제의 결과가 일치하는지 확인한다. 자동 검사는 실제 게임 플레이를 대체하지 않는다.
