# Mentalist 반사쉴드 플레이테스트

Debug는 난이도 2로 고정하고, 스테이지 진입 시 시작 위치 4~20m 안의 유효한 공간에 Mentalist 1마리를 생성한다. 시작 지점에는 샷건·권총·수면총·레이저총을 각각 1개 생성한다. 몬스터 위치 검색이 실패해도 총기는 먼저 생성한다. Release에는 임시 생성·키 조작·난이도 강제가 포함되지 않는다.

게임을 종료한 뒤 저장소 루트에서 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-RepoDev.ps1
```

호스트로 일반 스테이지에 들어가면 테스트 세트를 생성한다. 처음에는 테스트 Mentalist의 타깃 획득을 막아 반사쉴드를 바로 확인할 수 있다. 호스트의 **F6**으로 전환한다. OFF에서는 순정 인지·공격을 재개하며, ON으로 되돌리면 현재 타깃을 비우고 배회 상태로 복귀한다. 이 제어는 추가 생성한 테스트 개체에만 적용한다. ON인 동안에는 테스트 개체의 시간 만료 디스폰도 잠시 멈춘다. 위치 검색 실패나 총기 누락은 `DEBUG Mentalist` 로그에서 확인한다.

총을 쏜 뒤 2초 동안 옆으로 이동해 반격을 피하고, F6으로 정상 인지를 허용한 뒤 총격 피해·기절이 돌아오는지 비교한다. 바닐라 참가자는 같은 테스트에 참여할 수 있지만 F6 제어는 호스트만 한다.

1. 난이도 0·1에서는 반사가 없어야 한다. 난이도 2부터 타깃이 없는 Mentalist를 샷건·권총·수면총·레이저총으로 각각 맞힌다. 피해·기절 없이 항상 레이저총이 주변에 나타나야 한다. 샷건 산탄이 여러 개 맞아도 한 발당 레이저총 하나만 나와야 한다. 레이저 입력도 연속 발사 한 차례당 한 번만 반격한다. 반격 레이저는 2초 뒤 순정 레이저 발사 시간 동안 고정 사선으로 발사한 후 사라져야 한다.
2. 맞은 뒤 원래 위치에 남으면 2초 뒤 반격 레이저를 맞아야 한다. 총 생성 직후 사선에서 이동하면 조준이 따라오지 않고 원래 방향으로 발사해야 한다. 벽·문 뒤로 이동하면 순정 레이저 차폐 규칙을 따라야 한다. 수면총으로 발동시켜도 반격 피해·효과는 레이저여야 한다.
3. Mentalist가 이미 타깃을 보유한 상태에서는 같은 총격의 피해·기절이 정상 적용되고 반격 총이 없어야 한다. 타깃이 생기는 순간과 여러 산탄이 겹칠 때 한 발 내 보호 여부가 바뀌거나 반격이 중복되면 안 된다. 근접 무기·던진 물건 피해는 유지한다.
4. 서로 다른 플레이어가 서로 다른 총으로 연속 사격하면 모두 레이저총이 나타나고 각 공격자의 0초 위치 방향으로 쏘는지 확인한다. 임시 총의 Grab이 취소되고, 발사 후 총이 남거나 추출 보상으로 수집되지 않아야 한다. 원본 총이나 레이저총을 탄약 보상으로 남기면 안 된다.
5. 발동 후 타깃을 얻어도 원래 예약된 반격을 이어간다. 2초 안에 다른 공격으로 본체를 처치하거나 본체가 디스폰되면 총을 정리해야 한다. 스테이지 전환·방 종료에도 총이 남으면 안 된다.
6. 반격이 자기 본체에 피해를 주거나 다른 Mentalist와 무한 반사되면 안 된다. 다른 플레이어와 몬스터의 총격 판정은 순정대로 동작한다.
7. 호스트와 바닐라 참가자가 각각 사격하고 피해를 받는 경우를 확인한다. 총의 위치·조준 방향·소리·발사 시점·소멸과 오류 로그를 비교한다. 위치 동기화와 RPC 지연으로 표시상 2초와 판정 시점이 얼마나 차이나는지 확인한다.

자동 검사 506개와 Debug/Release 빌드는 실제 게임 플레이 검증을 대체하지 않는다.
