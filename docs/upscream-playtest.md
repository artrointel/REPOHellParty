# Upscream 변장 플레이테스트

Debug/Release 빌드와 자동 검사 후 실제 게임에서 확인할 항목이다. 호스트만 HellParty를 설치하고 바닐라 참가자와 함께 확인한다.

## 테스트 준비

게임을 종료한 뒤 저장소 루트에서 실행한다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Start-RepoDev.ps1
```

Upscream 테스트는 `[Debug.Headman]
Enabled = false

[Debug.Clown]
Enabled = false

[Debug.Reaper] Enabled = false`, `[Debug.Upscream] Enabled = true`로 선택한다. 난이도를 5로 유지하고 시작 위치 20m 이내의 연결된 NavMesh 지점에 변장 능력을 가진 Upscream 1마리, 시작 지점에 샷건·수면총 각 1개를 생성한다. 몬스터 위치 탐색이 실패해도 무기는 별도로 생성한다.

이 시나리오가 켜져 있으면 이전 Huntsman·Cleanup Crew의 테스트 생성과 전용 키 제어는 실행하지 않는다. Upscream은 별도 키 조작 없이 순정 배회 중 플레이어를 발견하면 변장한다. 본체와 시야가 통하는 20m 안으로 접근해 변장 수집품을 찾는다.

프로필의 `BepInEx/config/artrointel.HellParty.cfg`에서 `Debug.Upscream`을 false로 바꾸면 이전 시나리오를 선택할 수 있다. 종합 테스트는 Reaper·Upscream·Huntsman·CleanupCrew 여섯 시나리오를 모두 false로 바꾸고 재시작하거나 Release를 사용한다. Release에는 테스트 생성·강제 난이도·테스트 개체의 소환 예외 코드가 없다.

## 확인 순서

1. 20m 안에서 장애물 없이 플레이어가 보이면 수집품으로 변장해야 한다. 벽 뒤에서는 변장하지 않아야 한다. Release에서 난이도 0은 순정이며 1부터 변장이 적용되어야 한다.
2. 변장 수집품을 잡으면 Grab이 해제되고 기존 Upscream이 복귀해 잡은 플레이어에게 순정 인지 예고·접근·던지기 공격을 해야 한다. 공격 대상을 유지하는 동안 바로 다시 수집품으로 변장하면 안 된다.
3. 공격 대상이 사망하거나 순정 추격·공격이 종료되면 배회로 복귀하고 다음 조건 충족 시 다시 변장해야 한다. 공격 후 잠깐 Idle이 되는 동안에는 대상을 유지해야 한다.
4. 변장 중 벽 뒤로 숨거나 멀어져 연속 5초 동안 아무도 보이지 않으면 변장 수집품을 제거하고 공격 없이 배회해야 한다. 중간에 다시 보이면 타이머가 초기화되어야 한다.
5. 본체에 피해를 준 뒤 변장시키고 변장 수집품의 내구도에 같은 비율의 손실이 반영되는지 확인한다. 변장 수집품에서 추가 피해를 준 뒤 Grab 또는 시야 상실로 복귀시켜도 체력이 회복되면 안 된다.
6. 무기와 환경 충돌로 각각 변장 수집품을 파괴하여 Upscream 처치와 코어 보상 1개가 발생하는지 확인한다. Grab·파괴가 겹쳐도 중복 보상이나 살아 있는 본체 복귀가 발생하면 안 된다.
7. 드론이 변장 수집품에 부착되지 않고, 노움도 공격 대상 가치품으로 선택하지 않아야 한다. 일반 수집품은 기존대로 동작해야 한다.
8. 청소부의 부화2와 몬스터 웨이브에서 생성된 Upscream은 수집품으로 변장하면 안 된다. 부화2 개체의 초기 타깃·10초 수명·던지기 직후 디스폰·코어 미드랍, 웨이브 개체의 이벤트 종료 디스폰을 확인한다. 자연 생성 개체의 변장에는 이 소환수 수명 규칙을 적용하지 않는다.
9. 스테이지 전환·사망 후 남은 변장 수집품이나 지연 복귀가 없어야 한다. 호스트와 바닐라 참가자의 이동·변장·잡기 해제·파괴 보상을 각각 확인한다.
10. 재변장과 새 개체에서 [후보 24종](monsters/upscream.md) 중 하나가 무작위로 선택되는지 확인한다. 코어·Surplus·Telescope·Unicorn Horn은 나타나면 안 된다. Chef의 외형은 계속 Frog여야 한다. 큰 물체가 벽·바닥에 끼는지, 각 외형에서 Grab 해제·내구도 공유·파괴 보상이 유지되는지도 확인한다.

상세 사양은 [Upscream](monsters/upscream.md), 공통 규칙은 [Chef](monsters/chef.md)를 따른다.
