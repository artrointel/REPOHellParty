# HellParty v0.2.1 — 난이도 진행 안내 보완

**호스트만 설치하면 순정 R.E.P.O. 참가자들과 함께 즐길 수 있습니다.**

Meet the party 도입부에 헬파티 난이도가 3라운드마다 상승한다는 설명을 짧게 추가했습니다. 1·4·7·10·13라운드에서 각각 난이도 1·2·3·4·5가 되며 이후에는 5를 유지합니다. 순정 게임 난이도와 별개로 진행됩니다.

몬스터 소개표는 최종 강화 능력을 설명하며, 초반부터 모든 능력이 발동하는 것은 아니라는 점도 명시했습니다. 이번 업데이트는 소개문 보완이며 게임 동작은 변경하지 않습니다.

썬더스토어 소개 페이지는 Edit에서 `thunderstore/README.md`를 불러와 새 버전 없이 수정할 수 있습니다. 사이트 편집은 기존 다운로드 파일을 변경하지 않습니다. 다운로드 패키지까지 갱신하려면 `HellParty-0.2.1.zip`을 새 버전으로 업로드합니다.

패키지·체크섬·자동 검증 보고서는 `artifacts/HellParty-0.2.1.zip`, `artifacts/HellParty-0.2.1.zip.sha256`, `artifacts/HellParty-0.2.1.release.json`입니다.
