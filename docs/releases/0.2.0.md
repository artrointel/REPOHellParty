# HellParty v0.2.0 — 호스트만 설치하는 몬스터 파티

**호스트 한 명만 설치하면 모드 없는 친구들도 순정 R.E.P.O.로 함께 즐길 수 있습니다.**

**Only the host installs. Friends can join with vanilla R.E.P.O.**

## 새로운 위협: 엘사의 암살

조용히 따라오던 엘사 앞에서 일행과 너무 멀어지지 마세요. 고립된 플레이어에게 가까워지면 공격형으로 변신합니다. 동료가 곁으로 합류하면 암살 모드가 바로 풀리니, 서로의 위치를 확인하는 것이 새로운 대처법입니다. 암살이 끝나면 10초 동안 다시 암살 모드에 들어가지 않습니다.

이번 능력은 자연 생성 엘사에만 추가됩니다. 보우타이가 소환한 엘사는 기존 변신·공격·수명 규칙을 유지합니다. 기존 몬스터 능력과 몬스터 웨이브도 계속 사용할 수 있습니다.

Trudge 소집의 빈자리 탐색과 재시도를 보완했습니다. 웨이브·청소부 소환수는 퇴장 후 재사용해 반복 소환의 네트워크 ID 누적을 줄이고, 여유가 부족하면 추가 생성을 지연하거나 건너뜁니다. 이 변경의 실제 반복 멀티플레이 검증은 별도로 필요합니다.

청소부의 폭발헤드는 이제 머리에 달라붙고 가까운 동료에게 옮겨 붙습니다. Grab으로 떼어낼 수 있지만 폭발까지의 시간은 늘어나지 않습니다. 함께 모이면 위험도 돌려받는 폭탄돌리기를 조심하세요.

순정 수량에 1~4라운드는 중형 +1, 5~9라운드는 대형 +1, 10라운드부터 중형·대형 각각 +1을 더합니다. 참여 인원이 7명 이상이면 해당 보정이 각각 +2가 됩니다. 몬스터 선정과 출현 타이밍은 순정을 유지합니다.

## 설치와 업데이트

호스트가 HellParty와 BepInExPack을 설치합니다. 참가자에게는 추가 모드·BepInEx 설치나 별도 설정이 필요하지 않습니다. 게임을 종료한 뒤 이전 HellParty를 업데이트하고 DLL이 중복되지 않도록 확인하세요.

- 패키지: `HellParty-0.2.0.zip`.
- 체크섬: `HellParty-0.2.0.zip.sha256`.
- 자동 검증 보고서: `HellParty-0.2.0.release.json`.

엘사 능력의 실제 멀티플레이 검증은 자동 검사와 별도로 진행합니다. 저장소의 플레이테스트 안내를 따라 대상·구출 역할을 호스트와 바닐라 참가자가 번갈아 확인할 수 있습니다.
