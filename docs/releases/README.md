# 릴리즈 안내

각 버전의 공개용 소개문을 보관한다. GitHub·Thunderstore 등 게시 위치에 맞춰 본문을 사용하되, 제목과 첫 문단에는 **호스트만 설치하면 모드 없는 순정 참가자도 함께 플레이할 수 있다**는 장점을 유지한다. BepInEx와 HellParty 설치가 필요한 사람은 호스트임을 설치 안내에서도 명확히 구분한다.

- [0.2.0 공개용 소개문](0.2.0.md)
- [0.1.0 공개용 소개문](0.1.0.md)
- [배포 준비와 실제 플레이 확인](../release-readiness.md)

소개문은 플레이어가 겪을 변화와 설치 방법을 먼저 설명한다. 몬스터별 능력은 최종 강화 형태를 기준으로 소개하고, 자주 조정되는 해금 단계 표는 상세 기획 문서에서 관리한다. 실제로 실행하지 않은 플레이테스트를 완료했다고 쓰지 않는다.

`Verify-Release.ps1`이 성공하면 해당 버전의 소개문을 ZIP 옆으로 복사하고 ZIP용 `.sha256` 파일과 검증 보고서를 만든다. 공개 업로드와 Git 태그·커밋 생성은 이 도구가 수행하지 않는다.
