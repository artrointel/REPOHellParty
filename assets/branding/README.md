# HellParty 아이콘

왕관을 쓴 Apex Predator를 앞에, Clown과 Reaper를 양옆에 배치한 카툰 스타일 팬아트다. 왕관은 헬파티의 본체 오리 식별 장치를 표현한다. 세 얼굴과 큰 `HELL PARTY` 문구를 중심으로 작은 썸네일에서도 읽히도록 구성했다.

- 원본: [hellparty-icon-source.png](hellparty-icon-source.png).
- 패키지용 256×256 PNG: [icon.png](../../thunderstore/icon.png).
- 생성: 기본 내장 `imagegen` 도구, 불투명 정사각형 이미지.
- 최종 프롬프트: [icon-prompt.txt](icon-prompt.txt).
- 원본을 변경한 뒤 `scripts/New-PackageIcon.ps1`을 실행하면 비율을 유지해 패키지 아이콘을 다시 출력한다. 이 스크립트는 이미지를 새로 생성하거나 이전 문자 아이콘으로 되돌리지 않는다.

## 외형 참고

웹에서 아래 자료의 실제 모습을 확인한 뒤 새로 그렸다. 참고 스크린샷과 모델 이미지는 배포 패키지에 포함하지 않는다.

- Apex Predator: [PC Gamer의 오리 가이드](https://www.pcgamer.com/games/horror/repo-duck-guide/).
- Clown: [GamerBlurb의 몬스터 가이드](https://gamerblurb.com/articles/repo-monsters-list-and-guide).
- Reaper: [Lewix의 R.E.P.O. Reaper 모델 미리보기](https://sketchfab.com/3d-models/repo-monsters-reaper-542f242d2888475dac6ed0c4ee9de70b).

R.E.P.O.와 원래 몬스터 디자인은 semiwork의 작품이며 이 아이콘은 비공식 모드를 위한 재해석이다.
